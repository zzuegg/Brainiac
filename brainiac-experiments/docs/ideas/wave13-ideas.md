Target: one new package, `experimental.explain` (13.1.1–13.1.16), and a new theme `experiments.explainability` with `EffectPlots` (13.1.1), `ShapleyMethods` (13.1.2–13.1.4), `LocalRules` (13.1.5–13.1.6), `InterpretableNetworks` (13.1.7–13.1.9, 13.1.16), `InterpretableModels` (13.1.10–13.1.13) and `ExplanationEvaluation` (13.1.14–13.1.15). ### 13.1.1 Partial dependence, ICE and accumulated local effects, with Friedman's H-statistic (Friedman, Annals 2001; Goldstein et al., JCGS 2015; Apley & Zhu, JRSS-B 2020; Friedman & Popescu, AoAS 2008)
A partial dependence plot averages the model's prediction over the data while one feature is set to each grid value; ICE curves keep the individual lines, so heterogeneity and interactions show as non-parallel curves (c-ICE centres them). With correlated inputs both evaluate the model off the data manifold. ALE plots instead accumulate local finite differences of the prediction within quantile bins of the feature, using only points in each bin, so they stay on the data and are unbiased for additive effects under correlation. Friedman's H² measures the share of the variance of a pair's joint partial dependence not explained by the two one-way effects. The block computes all four for any `ToDoubleFunction<double[]>` model.
- **Block:** `experimental.explain.EffectPlots` (PDP, ICE, C_ICE, ALE first- and second-order, H_STATISTIC pairwise and total).
- **Experiment:** `experiments.explainability.EffectPlots`.
- **Toy task:** `PlantedFunctions` with five additive shapes (linear, quadratic, step, sine, saturating), one planted x₁·x₂ interaction, ρ ∈ {0, 0.5, 0.9}; models: GBT, random forest, MLP and the true function.
- **Baselines:** global KernelSHAP importance and dependence (`ModelAgnosticExplainer.kernelShap`, averaged), `ExplainableBoosting` shape functions, `NeuralAdditiveModel` shape functions, permutation importance.
- **Expected metric:** L2 error of the recovered effect curve against the planted g_j (on the data support), and H-statistic AUROC for detecting the true interacting pair. Hypothesis: PDP and ALE agree at ρ = 0; at ρ = 0.9 PDP error on the true function grows several-fold while ALE stays close; the H-statistic ranks the planted pair first for GBT and MLP, and EBM/NAM shape functions match ALE only where the model is truly additive.
- **Source:** [arXiv:1612.08468](https://arxiv.org/abs/1612.08468) (ALE); Friedman, "Greedy function approximation" (Annals 2001).

### 13.1.2 TreeSHAP: exact path-dependent and interventional Shapley values for tree ensembles (Lundberg et al., Nature Machine Intelligence 2020)
KernelSHAP approximates Shapley values by a weighted regression over sampled coalitions and needs thousands of model calls per row. For trees, TreeSHAP computes them exactly in O(TLD²) by pushing all subsets down each tree at once: the path-dependent version uses the training cover counts as the conditional distribution, and the interventional version averages exact values over a background set (O(TLB)). The interaction variant gives the SHAP interaction matrix. The block walks the trees of the core `GradientBoostedTrees` and `RandomForest` through a small read-only tree view (no change to the classes beyond a public accessor if needed, defaults unchanged).
- **Block:** `experimental.explain.TreeShap` (PATH_DEPENDENT, INTERVENTIONAL, interaction values), `experimental.explain.TreeView` (read-only adapter).
- **Experiment:** `experiments.explainability.ShapleyMethods` (tree table).
- **Toy task:** `PlantedFunctions` with p = 8–20 features, independent and correlated inputs; GBT with 100 trees of depth 4 and a 50-tree forest; brute-force Shapley over 2^p coalitions as ground truth at p = 8.
- **Baselines:** `ModelAgnosticExplainer.kernelShap` with 300–5000 samples; `ExplainabilityBenchmark`'s `TREE_GAIN` importance; saliency is not applicable to trees.
- **Expected metric:** max absolute error to brute force, time per row, and recovery of the planted relevant features. Hypothesis: interventional TreeSHAP matches brute force to 1e-9 at p = 8 and is ≥ 100× faster than KernelSHAP at equal error; path-dependent values differ from interventional ones under ρ = 0.9 (credit leaks to correlated irrelevant features); gain importance mis-ranks a high-cardinality noise feature that TreeSHAP ranks last.
- **Source:** [arXiv:1905.04610](https://arxiv.org/abs/1905.04610)

### 13.1.3 Shapley interactions: the Shapley interaction index, k-SII, Faith-Shap, SHAP-IQ sampling and TreeSHAP-IQ (Grabisch & Roubens, IJGT 1999; Tsai, Yeh & Ravikumar, JMLR 2023; Fumagalli et al., NeurIPS 2023; Muschalik et al., AAAI 2024)
First-order Shapley values hide interactions. The Shapley interaction index extends them to pairs; k-SII builds an efficient explanation that sums to the prediction with all interactions up to order k; Faith-Shap is the faithful least-squares interaction expansion. SHAP-IQ estimates any cardinal interaction index from one set of sampled coalitions with a unified estimator, and TreeSHAP-IQ computes them exactly for trees with polynomial arithmetic along paths. The block gives exact (enumeration) values for small p, the sampling estimator for black boxes, and the tree algorithm.
- **Block:** `experimental.explain.ShapleyInteractions` (SII, K_SII, STII, FAITH_SHAP; EXACT, SHAP_IQ sampling, TREE).
- **Experiment:** `ShapleyMethods` (interaction table).
- **Toy task:** `PlantedFunctions` with planted pairwise and one three-way interaction, p = 8–12; GBT and MLP models.
- **Baselines:** 13.1.1's H-statistic; the SHAP interaction matrix from 13.1.2; KernelSHAP first-order values (which cannot separate interactions).
- **Expected metric:** precision@k of planted interacting pairs, error to exact indices versus model calls, efficiency gap of the explanation. Hypothesis: k-SII (k = 2) finds the planted pairs with precision ≥ 0.9 where the H-statistic is noisier at n = 500; SHAP-IQ reaches the exact values' ranking with ~10× fewer calls than permutation-based pair estimates; TreeSHAP-IQ matches enumeration exactly.
- **Source:** [arXiv:2303.01179](https://arxiv.org/abs/2303.01179) (SHAP-IQ); Tsai et al., "Faith-Shap" (JMLR 2023).

### 13.1.4 Fast model-agnostic Shapley estimators: permutation sampling with antithetic pairs, paired KernelSHAP and Leverage SHAP (Štrumbelj & Kononenko, KAIS 2014; Covert & Lee, AISTATS 2021; Musco & Witter, ICLR 2025)
KernelSHAP solves a weighted least-squares problem on sampled coalitions; its error is hard to bound. Permutation sampling averages marginal contributions along random feature orders, and antithetic (reversed) orders cut its variance. Paired sampling adds the complement of every sampled coalition. Leverage SHAP observes that the Shapley regression is a least-squares problem whose rows can be sampled by their statistical leverage scores, which have a closed form, and samples coalition sizes by leverage without replacement; it needs O(n log n) evaluations for a provable (1+ε) guarantee and is a small change to KernelSHAP.
- **Block:** `experimental.explain.ShapleyEstimators` (PERMUTATION, ANTITHETIC_PERMUTATION, KERNEL_SHAP_PAIRED, LEVERAGE_SHAP, with a common evaluation budget).
- **Experiment:** `ShapleyMethods` (estimator table).
- **Toy task:** the GBT models of 13.1.2 (exact TreeSHAP as ground truth) at p ∈ {8, 16, 32}, and an MLP at p = 12 with brute-force truth.
- **Baselines:** `ModelAgnosticExplainer.kernelShap` unchanged; exact values from 13.1.2.
- **Expected metric:** mean squared error to the exact values at budgets of 2p, 8p and 32p evaluations, over 20 rows. Hypothesis: Leverage SHAP has the lowest error at every budget and the advantage grows with p; antithetic permutation sampling beats plain permutation by ≥ 2× in MSE; paired KernelSHAP closes most of the gap to Leverage SHAP at 32p.
- **Source:** [arXiv:2410.01917](https://arxiv.org/abs/2410.01917)

### 13.1.5 Anchors: high-precision rule explanations by bandit search (Ribeiro, Singh & Guestrin, AAAI 2018)
An anchor is a conjunction of feature predicates such that, when the predicates hold, the model's prediction stays the same with high probability (precision ≥ τ) under a perturbation distribution, while covering as many inputs as possible. Anchors are found by a beam search over predicates in which each candidate's precision is estimated with the KL-LUCB best-arm identification bandit, so model calls go to the candidates whose precision is uncertain. The block discretises features into quantile bins and perturbs by sampling other rows conditioned on the anchor.
- **Block:** `experimental.explain.Anchors` (beam width, τ, δ, KL-LUCB; `coverage()` and `precision()`).
- **Experiment:** `experiments.explainability.LocalRules`.
- **Toy task:** `PlantedFunctions` binary tasks whose label follows a known rule (e.g. x₁ > 0.5 ∧ x₃ < 0) plus noise features; a GBT and an MLP fitted to it.
- **Baselines:** `ModelAgnosticExplainer.lime` turned into a rule by thresholding its top-k weights (the comparison of the paper); KernelSHAP top-k features as a rule.
- **Expected metric:** held-out precision and coverage of the explanation, and the share of rows whose explanation names exactly the planted features; model calls per explanation. Hypothesis: anchors reach precision ≥ 0.95 where LIME-derived rules sit at 0.7–0.85 on rows near the boundary, with coverage close to the planted rule's; KL-LUCB uses ≥ 3× fewer calls than uniform sampling at the same precision guarantee.
- **Source:** Ribeiro, Singh & Guestrin, "Anchors: High-precision model-agnostic explanations" (AAAI 2018).

### 13.1.6 Actionable recourse and diverse counterfactuals: integer-programming recourse, DiCE, FACE and robust recourse (Ustun, Spangher & Liu, FAT* 2019; Mothilal, Sharma & Tan, FAT* 2020; Poyiadzi et al., AIES 2020; Upadhyay, Joshi & Lakkaraju, NeurIPS 2021)
A counterfactual explanation tells a person what to change to flip a decision, but Wachter-style gradient search may change immutable features, leave the data manifold or give one brittle answer. Actionable recourse for a linear model is a small integer program over discretised feature changes with immutability and monotonicity constraints and per-feature costs. DiCE optimises several counterfactuals jointly with a determinantal diversity term. FACE finds feasible paths through a k-NN density graph, so the recourse stays in high-density regions. Robust recourse (ROAR, not to be confused with 13.1.14's remove-and-retrain) optimises against the worst case over a set of model updates.
- **Block:** `experimental.explain.Recourse` (LINEAR_IP via the core `Optimize.linearProgram` relaxation plus wave 11's `BranchAndBound`, DICE, FACE, ROBUST).
- **Experiment:** `LocalRules` (recourse table).
- **Toy task:** `PlantedFunctions` credit-style data with immutable (age-like), monotone (only increase) and costly features; logistic regression, GBT and MLP; the model is retrained on shifted data to test robustness.
- **Baselines:** `ModelAgnosticExplainer.counterfactual` (Wachter), scored by `ExplainabilityBenchmark`'s validity/sparsity metrics; nearest unlike neighbour in the training set (via `KnnIndex`).
- **Expected metric:** validity, actionability (no immutable change), cost, k-NN density of the counterfactual, diversity (mean pairwise distance of k = 4), and validity after a model update. Hypothesis: Wachter violates immutability on 20–40% of rows where the IP never does at a comparable cost; FACE has the highest density and the highest cost; DiCE's sets cover more distinct features; robust recourse keeps ≥ 0.9 validity after the update where plain recourse drops to 0.5–0.7.
- **Source:** [arXiv:1809.06514](https://arxiv.org/abs/1809.06514) (actionable recourse), [arXiv:1905.07697](https://arxiv.org/abs/1905.07697) (DiCE).

### 13.1.7 Prototypical-part networks: ProtoPNet with ℓ2 and cosine similarity (Chen et al., NeurIPS 2019; Moffett et al., WACV 2026)
ProtoPNet ("this looks like that") puts a layer of learned prototype vectors after a CNN backbone; each prototype's similarity to the closest patch of the feature map feeds a sparse linear head, so a decision is explained by "these patches resemble these training patches". Training alternates SGD with cluster and separation costs, a projection step that snaps every prototype to its nearest real training patch, and a last-layer convex fit. The WACV 2026 paper replaces the ℓ2-based log-activation by cosine similarity and reports less hyperparameter sensitivity and better prototypes across five variants.
- **Block:** `experimental.explain.PrototypeLayer` (L2_LOG, COSINE; projection; last-layer sparsity) and `experimental.explain.ProtoPNet`.
- **Experiment:** `experiments.explainability.InterpretableNetworks` (prototype table).
- **Toy task:** `ConceptShapes` classification (6 classes defined by shape and texture), 24×24, with concept masks for scoring.
- **Baselines:** the same backbone with a linear head (`ShapesCnn`-style), explained by `GradCam` and `Attribution.integratedGradients`; a k-NN on backbone features (`KnnIndex`), the non-parametric "this looks like that" baseline.
- **Expected metric:** accuracy, the share of top-activated prototype patches that fall inside the relevant concept mask (prototype purity), and accuracy spread over three learning rates. Hypothesis: ProtoPNet costs ≤ 3 points of accuracy against the black box; cosine similarity halves the accuracy spread across learning rates and raises purity; Grad-CAM pointing on the black box is comparable to prototype purity, but only prototypes give case-based explanations.
- **Source:** [arXiv:1806.10574](https://arxiv.org/abs/1806.10574); [WACV 2026 poster](https://wacv.thecvf.com/virtual/2026/poster/735).

### 13.1.8 Concept bottleneck models, interventions, concept embedding models and leakage (Koh et al., ICML 2020; Espinosa Zarlenga et al., NeurIPS 2022; Parisini et al., May 2025)
A concept bottleneck model predicts human concepts first (x → c) and the label only from them (c → y), so a user can inspect and correct ("intervene on") concepts at test time. Independent, sequential and joint training trade accuracy against how faithful the bottleneck is; soft joint bottlenecks can leak extra label information through the concept probabilities. Concept embedding models give each concept a learned embedding mixed by its probability, regaining accuracy. The 2025 paper defines concepts–task leakage (CTL) and inter-concept leakage (ICL) as information-theoretic excess over ground-truth concepts and shows that they predict how well interventions work; it finds CEMs leak substantially.
- **Block:** `experimental.explain.ConceptBottleneck` (INDEPENDENT, SEQUENTIAL, JOINT_SOFT, JOINT_HARD, CEM; `intervene(int[] concepts)`) and `experimental.explain.ConceptLeakage` (CTL, ICL with binned or KSG MI from wave 12's `estimators.MutualInformation`).
- **Experiment:** `InterpretableNetworks` (concept table).
- **Toy task:** `ConceptShapes` with 5 binary concepts and a label that is a boolean function of them; an incomplete-concepts variant where the label also depends on an unlabelled concept.
- **Baselines:** the end-to-end CNN; the CNN with `ConceptActivationVectors` (TCAV) probes for concept accuracy.
- **Expected metric:** task accuracy, concept accuracy, accuracy after intervening on 0–5 concepts, CTL/ICL. Hypothesis: hard and sequential CBMs gain the most from interventions (to ≈ 1.0 with all concepts corrected) and have near-zero leakage; soft joint CBMs and CEMs match the black box in accuracy, show the highest CTL and gain least from interventions; leakage rank-correlates with intervention gain (negative) across models, as the 2025 paper reports.
- **Source:** [arXiv:2007.04612](https://arxiv.org/abs/2007.04612), [arXiv:2504.14094](https://arxiv.org/abs/2504.14094)

### 13.1.9 Self-explaining neural networks (Alvarez-Melis & Jaakkola, NeurIPS 2018)
SENN generalises a linear model to f(x) = Σ_k θ_k(x) h_k(x): interpretable basis concepts h(x) (raw features or an autoencoder's codes) weighted by input-dependent relevances θ(x) from a network, with a robustness regulariser that makes θ locally constant (‖∇f − θ(x)ᵀJ_h‖), so the relevances are faithful local explanations. The paper measures explanation stability by a local Lipschitz estimate.
- **Block:** `experimental.explain.SelfExplainingNetwork` (identity or autoencoder concepts, robustness weight λ).
- **Experiment:** `InterpretableNetworks` (SENN table).
- **Toy task:** `PlantedFunctions` regression and classification with known local coefficients (a varying-coefficient model y = Σ β_j(z) x_j); `ToyTasks` digits with 5 autoencoder concepts.
- **Baselines:** `NeuralAdditiveModel`, `ExplainableBoosting`, an MLP explained by `ModelAgnosticExplainer.lime` and by input gradients (`Attribution.saliency`).
- **Expected metric:** accuracy, correlation of θ(x) with the true local coefficients, and the local Lipschitz estimate of the explanation. Hypothesis: SENN recovers the varying coefficients (correlation ≥ 0.8) where NAM/EBM cannot represent them; its explanations are 5–10× more stable than LIME or gradients on the MLP, at ≤ 2 points of accuracy cost.
- **Source:** [arXiv:1806.07538](https://arxiv.org/abs/1806.07538)

### 13.1.10 Rule ensembles and certifiably optimal rule lists: RuleFit and CORELS (Friedman & Popescu, AoAS 2008; Angelino et al., JMLR 2018)
RuleFit extracts every root-to-node path of a boosted tree ensemble as a binary rule and fits a sparse linear model (the lasso) over the rules and the raw features, giving a short list of weighted rules. CORELS searches the space of ordered if-then-else rule lists over pre-mined antecedents by branch-and-bound with a regularised objective (misclassification + λ·length), using bounds on prefixes, equivalent-support pruning and a prefix permutation map, and certifies optimality.
- **Block:** `experimental.explain.RuleFit` (uses wave 12's `stats.PenalizedRegression` lasso) and `experimental.explain.RuleLists` (CORELS with frequent-itemset antecedents, max cardinality 2).
- **Experiment:** `experiments.explainability.InterpretableModels` (rules table).
- **Toy task:** `PlantedFunctions` binarised tasks with a planted 3-rule list plus label noise 0–10%; a COMPAS-like synthetic with 12 binary features.
- **Baselines:** a single depth-limited tree (one `RandomForest` tree with all features), core `GradientBoostedTrees`, `ExplainableBoosting`, L1 logistic regression.
- **Expected metric:** accuracy, number of rules/conditions, recovery of the planted list, and CORELS's certificate time. Hypothesis: CORELS recovers the planted list exactly at ≤ 5% noise and certifies optimality in under a second at 12 features; RuleFit reaches GBT-level accuracy with 10–30 rules; the greedy tree needs more leaves for the same accuracy.
- **Source:** [arXiv:1704.01701](https://arxiv.org/abs/1704.01701) (CORELS); Friedman & Popescu (AoAS 2008).

### 13.1.11 Optimal sparse decision trees by dynamic programming with bounds: DL8.5 and GOSDT (Aglin, Nijssen & Schaus, AAAI 2020; Lin et al., ICML 2020)
Greedy CART splits can be far from the best tree of a given depth. DL8.5 finds the optimal depth-limited tree on binary features by a depth-first search over itemsets with caching of sub-problems and upper-bound pruning; GOSDT optimises misclassification plus a per-leaf penalty with dynamic programming over subproblems identified by bit-vectors of covered samples, with lower bounds (equivalent points, one-step lookahead) and supports. The block implements the cached DP with bounds on binarised features (threshold guessing from a GBT, as in the follow-up "How smart guessing strategies can yield massive scalability improvements", AAAI 2022).
- **Block:** `experimental.explain.OptimalTrees` (DL85 depth-limited, GOSDT-style penalised; threshold guessing; returns the cache for 13.1.12).
- **Experiment:** `InterpretableModels` (tree table).
- **Toy task:** `PlantedFunctions` with a planted depth-3 tree (XOR-like splits that greedy trees cannot find) and 10–20 binarised features; n = 500–2000.
- **Baselines:** greedy CART (one `RandomForest` tree); core `GradientBoostedTrees` as the accuracy ceiling; 13.1.10's rule lists.
- **Expected metric:** test accuracy at depth 2–4, number of leaves, optimality gap of CART, and solve time. Hypothesis: on XOR-like planted trees the optimal depth-3 tree recovers the structure (accuracy ≈ 1 − noise) where CART at depth 3 is 10–25 points worse; solve time stays under 2 s with threshold guessing and grows ≥ 10× without it.
- **Source:** [arXiv:2006.08690](https://arxiv.org/abs/2006.08690) (GOSDT); Aglin et al. (AAAI 2020).

### 13.1.12 Rashomon sets and predictive multiplicity: SORTD anytime enumeration, ambiguity/discrepancy and Rashomon importance (Arslan et al., NeurIPS 2025; Marx, Calmon & Ustun, ICML 2020; Donnelly et al., NeurIPS 2023)
Many near-optimal models can disagree on individual predictions and on which features matter. The Rashomon set is all models within ε of the best objective. SORTD enumerates the Rashomon set of sparse trees in order of objective, best first, by keeping a sorted solution list at every DP node and combining left and right subtree solutions lazily, so it can stop at any time with a valid prefix of the set. Predictive multiplicity is measured by ambiguity (share of points whose prediction some ε-good model flips) and discrepancy (max share flipped by one model); the Rashomon importance distribution reports a feature's importance over the set rather than for one model.
- **Block:** `experimental.explain.RashomonSet` (SORTD on 13.1.11's cache, a brute-force reference for tiny depths; AMBIGUITY, DISCREPANCY, RASHOMON_RATIO, importance distribution).
- **Experiment:** `InterpretableModels` (multiplicity table).
- **Toy task:** `PlantedFunctions` with redundant features (copies with noise) so that many equally good trees exist; depth 3, ε ∈ {0.5%, 1%, 2%}.
- **Baselines:** multiplicity estimated by retraining with random seeds and bootstrap resamples (GBT and `RandomForest` trees), the common proxy; single-model permutation importance.
- **Expected metric:** Rashomon set size against ε, time to the first k trees, ambiguity and discrepancy, and the spread of importance for redundant features. Hypothesis: SORTD yields the first 100 trees in well under a second and matches brute force exactly; seed/bootstrap retraining underestimates ambiguity by ≥ 2×; redundant features show wide importance distributions where single-model importance gives one arbitrary answer.
- **Source:** [arXiv:2511.03344](https://arxiv.org/abs/2511.03344) (SORTD); [arXiv:1909.06677](https://arxiv.org/abs/1909.06677) (predictive multiplicity).

### 13.1.13 Sparse integer scoring systems: RiskSLIM and FasterRisk (Ustun & Rudin, JMLR 2019; Liu et al., NeurIPS 2022)
Medical risk scores add a few small integer points and map the total to a risk through a logistic curve. RiskSLIM solves the integer, ℓ0-constrained logistic-loss problem by a cutting-plane MIP (lattice cutting planes on the convex loss over the integer coefficients). FasterRisk instead builds a pool of good sparse continuous solutions by beam search with a sparse-diverse step, then rounds each by a star-ray search over multipliers and integer sequential rounding, which is fast and nearly as good.
- **Block:** `experimental.explain.ScoringSystems` (RISK_SLIM via cutting planes on `Optimize.linearProgram` plus `BranchAndBound`, FASTER_RISK; coefficient range ±5, sparsity k ≤ 5).
- **Experiment:** `InterpretableModels` (scoring table).
- **Toy task:** `PlantedFunctions` credit-style data whose true log-odds is a sparse integer score, and a nonlinear variant; n = 1000, p = 20.
- **Baselines:** L1 logistic regression (`stats.PenalizedRegression`) rounded to integers (the naive approach), unconstrained logistic regression, `ExplainableBoosting`.
- **Expected metric:** test log loss, AUROC, calibration (ECE) and model size; solve time. Hypothesis: naive rounding loses 0.02–0.05 AUROC and is badly calibrated; RiskSLIM and FasterRisk recover the planted score and stay within 0.01 AUROC of the continuous logistic model; FasterRisk is ≥ 10× faster than the cutting-plane MIP at equal loss.
- **Source:** [arXiv:1610.00168](https://arxiv.org/abs/1610.00168) (RiskSLIM), [arXiv:2210.05846](https://arxiv.org/abs/2210.05846) (FasterRisk).

### 13.1.14 Evaluating attributions: remove-and-retrain (ROAR), infidelity and max-sensitivity, and randomisation sanity checks (Hooker et al., NeurIPS 2019; Yeh et al., NeurIPS 2019; Adebayo et al., NeurIPS 2018)
Deletion curves without retraining confound "the feature mattered" with "the input left the training distribution". ROAR removes the top-k attributed features from the training and test sets, retrains, and measures the accuracy drop; a better attribution causes a larger drop. Infidelity is the expected squared difference between the attribution's dot product with a perturbation and the actual output change; max-sensitivity is the largest attribution change under small input perturbations. Sanity checks randomise the model weights layer by layer (or the labels) and require the attribution to change; maps that survive randomisation are explaining the input, not the model.
- **Block:** `experimental.explain.AttributionEvaluation` (ROAR, KAR, INFIDELITY, MAX_SENSITIVITY, MODEL_RANDOMISATION, DATA_RANDOMISATION).
- **Experiment:** `experiments.explainability.ExplanationEvaluation`.
- **Toy task:** `PlantedFunctions` tabular (MLP and GBT, with known relevant features) and `ConceptShapes` images (shapes CNN, with masks).
- **Baselines:** the attribution methods themselves (KernelSHAP, LIME, IG, SmoothGrad, saliency, Grad-CAM, random) and `ExplainabilityBenchmark`'s deletion AUC and pointing score.
- **Expected metric:** ROAR accuracy drop at k = 10–50%, infidelity, max-sensitivity, and SSIM/rank correlation between maps before and after randomisation. Hypothesis: the deletion-AUC ranking and the ROAR ranking disagree for at least one pair of methods; SmoothGrad and KernelSHAP beat saliency on infidelity and sensitivity; raw saliency and Grad-CAM change after randomisation while an edge-detector-like "map" (the input gradient times input on a random net) passes deletion but fails the sanity check.
- **Source:** [arXiv:1806.10758](https://arxiv.org/abs/1806.10758) (ROAR), [arXiv:1901.09392](https://arxiv.org/abs/1901.09392) (infidelity), [arXiv:1810.03292](https://arxiv.org/abs/1810.03292) (sanity checks).

### 13.1.15 Network dissection and compositional unit explanations (Bau et al., CVPR 2017; Mu & Andreas, NeurIPS 2020)
Network dissection labels every convolutional unit by thresholding its upsampled activation map at the top 0.5% quantile over a dataset and computing IoU with every concept's segmentation mask; a unit is a detector for the concept of highest IoU above a threshold. Compositional explanations search by beam search over logical formulas of concepts (AND, OR, NOT) for the formula whose mask best matches the unit, revealing polysemantic units.
- **Block:** `experimental.explain.NetworkDissection` (unit IoU, detector counts, compositional beam search up to length 3).
- **Experiment:** `ExplanationEvaluation` (dissection table).
- **Toy task:** `ConceptShapes` with per-pixel concept masks (shape, colour, texture, position) and the shapes CNN trained on the label; a version trained with a spurious background patch.
- **Baselines:** `ConceptActivationVectors` (TCAV) directions and scores per concept; random directions in the same layer (the control for TCAV and dissection).
- **Expected metric:** number of unique concept detectors per layer, mean best IoU, the share of units better explained by a formula than a single concept, and agreement between dissection and TCAV on which concepts the model uses. Hypothesis: later layers have more shape detectors and earlier ones colour/texture detectors; in the spurious model several units detect the background patch, which TCAV also flags; compositional formulas raise IoU by 20–50% for a third of the units; random directions give near-zero IoU.
- **Source:** [arXiv:1704.05796](https://arxiv.org/abs/1704.05796); Mu & Andreas, "Compositional explanations of neurons" (NeurIPS 2020).

### 13.1.16 Explanation-guided training: right for the right reasons (Ross, Hughes & Doshi-Velez, IJCAI 2017; Rieger et al., ICML 2020)
If a user marks input regions that should not matter (an annotation mask A), the "right for the right reasons" loss adds λ‖A ⊙ ∂ log p(y|x)/∂x‖² to the cross-entropy, penalising input-gradient attribution on those regions so the model is pushed towards other features. Contextual decomposition explanation penalisation (CDEP) penalises a decomposition-based attribution instead. The test is whether a model trained on data with a spurious shortcut generalises when the shortcut breaks.
- **Block:** `experimental.explain.ExplanationRegularizer` (RRR input-gradient penalty via double backprop, an integrated-gradients variant, mask sources: full masks or a few annotated examples).
- **Experiment:** `InterpretableNetworks` (guided-training table).
- **Toy task:** `ConceptShapes` with a background patch that predicts the label 95% of the time in training and 50% at test; `PlantedFunctions` with a leaky feature.
- **Baselines:** plain ERM; `GroupRobustTraining` (GroupDRO and JTT with group labels); last-layer retraining; data augmentation that randomises the patch.
- **Expected metric:** test accuracy when the shortcut breaks, the share of Grad-CAM mass on the patch, and accuracy on the shortcut-aligned split. Hypothesis: ERM collapses to 50–60% when the shortcut breaks; RRR with masks on 10% of the training images recovers most of the gap (≥ 85%), close to GroupDRO, which needs group labels for every example; Grad-CAM mass on the patch drops from > 0.5 to < 0.1.
- **Source:** [arXiv:1703.03717](https://arxiv.org/abs/1703.03717); Rieger et al., "Interpretations are useful" (ICML 2020).

### 13.2.1 STRIPS forward search with delete-relaxation heuristics: h_max, h_add and h_FF with greedy best-first and lazy search (Bonet & Geffner, AIJ 2001; Hoffmann & Nebel, JAIR 2001; Richter & Helmert, ICAPS 2009)
Classical planners search the state space of a STRIPS task with heuristics computed on the delete relaxation, in which actions never remove facts. h_max (admissible) takes the costliest precondition, h_add sums them, and h_FF extracts an explicit relaxed plan from the best-supporter graph and counts its actions; the relaxed plan also yields preferred operators. Greedy best-first search with h_FF, lazy evaluation (evaluating a node's heuristic only when it is expanded) and a preferred-operator queue is the core of FF and LAMA.
- **Block:** `experimental.symbolic.StripsTask`, `experimental.symbolic.RelaxationHeuristics` (H_MAX, H_ADD, H_FF, preferred operators) and `experimental.symbolic.StateSpaceSearch` (A*, GBFS, LAZY_GBFS, dual queue), built on wave 12's `GraphSearch` generic search where its interface fits.
- **Experiment:** `experiments.symbolic.ClassicalPlanning`.
- **Toy task:** `PlanningDomains` Blocksworld (4–10 blocks), Gripper (4–20 balls), Logistics-lite, VisitAll 4×4–8×8, Ferry.
- **Baselines:** blind search and BFS/Dijkstra (`GraphSearch`); A* with a goal-count heuristic; for the 8-puzzle, wave 12's Manhattan and DAVI heuristics (`LearnedHeuristic`).
- **Expected metric:** coverage within 10⁵ expansions, expansions, plan cost relative to optimal (where A* with h_max proves it), and time. Hypothesis: GBFS with h_FF solves every instance in ≤ 10⁴ expansions where blind search fails beyond 6 blocks; h_add and h_FF expand 10–100× fewer nodes than goal count; lazy search with preferred operators halves h_FF evaluations; h_max with A* is optimal but expands 10–50× more.
- **Source:** Bonet & Geffner, "Planning as heuristic search" (AIJ 2001); Hoffmann & Nebel, "The FF planning system" (JAIR 2001).

### 13.2.2 Landmarks: LM-cut and landmark-count heuristics (Helmert & Domshlak, ICAPS 2009; Richter & Westphal, JAIR 2010)
A landmark is a fact or action set that every plan must achieve or use. LM-cut computes h_max, finds a cut of the justification graph separating the initial state from the goal, records it as a disjunctive action landmark whose cost is its cheapest action, reduces costs and repeats; the sum is admissible and usually much closer to optimal than h_max. LAMA's landmark-count heuristic counts landmarks not yet reached (found by back-chaining from the goals with orderings) and is inadmissible but very informative for satisficing search.
- **Block:** `experimental.symbolic.Landmarks` (LM_CUT, landmark generation by RHW back-chaining, LANDMARK_COUNT, landmark orderings).
- **Experiment:** `ClassicalPlanning` (landmark table).
- **Toy task:** the 13.2.1 domains with unit and non-unit action costs.
- **Baselines:** 13.2.1's h_max (admissible) and h_FF (satisficing); blind A*.
- **Expected metric:** expansions to an optimal plan for A* with h_max vs LM-cut, h-value at the initial state against h*, and satisficing coverage/cost for GBFS with h_FF vs h_FF + landmark count (alternating queues, LAMA-style). Hypothesis: LM-cut cuts optimal-search expansions by 10–100× against h_max and has h(s₀)/h* ≥ 0.8 on Gripper and Logistics; adding landmark count to h_FF raises coverage on the larger Logistics instances.
- **Source:** Helmert & Domshlak, "Landmarks, critical paths and abstractions" (ICAPS 2009); Richter & Westphal (JAIR 2010).

### 13.2.3 Abstraction heuristics: pattern databases with the canonical heuristic (Culberson & Schaeffer, Comput. Intell. 1998; Edelkamp, ECP 2001; Haslum et al., AAAI 2007)
A pattern database projects the task onto a subset of variables (a pattern), solves the abstract space exactly by backward breadth-first search, and stores the abstract goal distances; the lookup is an admissible heuristic. Several PDBs combine by maximum, or additively when no action affects two patterns; the canonical heuristic takes the maximum over all maximal additive subsets. Pattern selection by hill climbing (iPDB) adds the variables that most improve a sample of h-values.
- **Block:** `experimental.symbolic.PatternDatabases` (single PDB, additive disjoint PDBs for the sliding-tile puzzle, CANONICAL, iPDB hill climbing over a multi-valued (SAS⁺) view built from mutex groups).
- **Experiment:** `ClassicalPlanning` (abstraction table).
- **Toy task:** the 8-puzzle (exact optimal costs known), Blocksworld, Gripper.
- **Baselines:** 13.2.2's LM-cut; wave 12's Manhattan + linear-conflict and DAVI heuristics (`LearnedHeuristic`) on the 8-puzzle; h_max.
- **Expected metric:** expansions of optimal A*, PDB build time and memory. Hypothesis: the additive 4+4 PDB beats Manhattan + linear conflict by ≥ 2× in expansions on the 8-puzzle and is admissible (unlike DAVI's 50% inadmissible estimates); on Gripper the canonical heuristic beats single PDBs and roughly ties LM-cut.
- **Source:** Edelkamp, "Planning with pattern databases" (ECP 2001); Haslum et al., "Domain-independent construction of pattern database heuristics" (AAAI 2007).

### 13.2.4 Learned heuristics with Weisfeiler–Leman graph features: WL-GOOSE (Chen, Trevizan & Thiébaux, ICAPS 2024 and NeurIPS 2023 GenPlan workshop)
Learned planning heuristics must generalise across instance sizes. WL-GOOSE encodes each state with its goal as an instance learning graph (objects, facts and goal facts as coloured nodes), runs a few rounds of WL colour refinement, and uses the histogram of colours as a fixed feature vector; a linear model (SVR or Gaussian-process regression) on those features is trained on optimal plan costs from small instances. The ICAPS paper reports that this beats GNN heuristics in coverage and training cost and is competitive with h_FF, and that the GP variant gives uncertainty.
- **Block:** `experimental.symbolic.WlFeatures` (instance learning graph, WL iterations, colour vocabulary from training) and `experimental.symbolic.LearnedPlanningHeuristic` (LINEAR_RIDGE, GP via `GaussianProcess`, GNN via `GinLayer`).
- **Experiment:** `experiments.symbolic.LearnedPlanning`.
- **Toy task:** `PlanningDomains` Blocksworld, Gripper, Ferry and VisitAll; train on small instances with optimal costs (A* + LM-cut from 13.2.2), test on 2–4× larger.
- **Baselines:** h_FF (13.2.1) and blind search; a GNN heuristic (`GinLayer` on the same graph); wave 12's DAVI training scheme as a reference for value-iteration-style training.
- **Expected metric:** coverage and expansions on the larger test instances, training time. Hypothesis: WL + ridge trains in under a second and beats the GNN in coverage on Blocksworld and Ferry; it beats h_FF in expansions on Gripper and Ferry and loses on Blocksworld; the GP's predictive variance is higher on out-of-distribution sizes.
- **Source:** [arXiv:2403.16508](https://arxiv.org/abs/2403.16508)

### 13.2.5 Ranking losses and partial-space search with learned action-set heuristics (Garrett, Kaelbling & Lozano-Pérez, IJCAI 2016; Wang & Trevizan, AAAI 2025)
A heuristic used by GBFS only needs to order states correctly, so learning to rank successors (the chosen state below its siblings on optimal plans) can generalise better than regressing cost-to-go. Partial-space search instantiates one action-schema argument at a time, which cuts the effective branching factor on tasks with many ground actions; the planner then scores a state together with a set of applicable actions (an action-set heuristic), learned from WL features of action-object graphs with a ranking-based linear model; the paper's LazyLifted planner beats WL-GOOSE and LAMA in coverage on high-branching benchmarks.
- **Block:** `experimental.symbolic.RankingHeuristic` (pairwise ranking loss on WL features) and `experimental.symbolic.PartialSpaceSearch` (argument-wise instantiation, action-set heuristic scoring).
- **Experiment:** `LearnedPlanning` (ranking table).
- **Toy task:** the 13.2.4 domains plus a high-branching Logistics-lite (many packages and trucks) and Ferry with many cars.
- **Baselines:** 13.2.4's regression heuristic; h_FF; full grounded GBFS.
- **Expected metric:** coverage, expansions and generated nodes on test instances. Hypothesis: the ranking loss beats regression on ≥ 3 of 4 domains at equal features; partial-space search cuts generated nodes by ≥ 3× on high-branching Logistics and gives little benefit on Blocksworld, as the paper reports for low-branching tasks.
- **Source:** [arXiv:2504.20318](https://arxiv.org/abs/2504.20318); Garrett et al., "Learning to rank for synthesizing planning heuristics" (IJCAI 2016).

### 13.2.6 Generalised planning with learned transition models and learned policies (Gupta et al., ICAPS 2026; Ståhlberg, Bonet & Geffner, KR 2022)
Instead of a heuristic, generalised planning learns something that runs without search. The ICAPS 2026 paper learns a goal-conditioned transition model: a small LSTM or gradient-boosted model predicts the residual change of a WL graph embedding of the state, and each predicted successor is snapped to the nearest valid symbolic successor, so every step is applicable; WL embeddings extrapolate to larger instances far better than fixed-size encodings. Learned general policies (a GNN that scores successor states, trained on optimal plans) are the reference approach.
- **Block:** `experimental.symbolic.GeneralizedPlanner` (TRANSITION_MODEL with ridge or core `GradientBoostedTrees` on WL residuals and nearest-valid-successor snapping; GNN_POLICY greedy successor selection).
- **Experiment:** `LearnedPlanning` (generalisation table).
- **Toy task:** Blocksworld, Gripper, VisitAll and Logistics-lite; train on small sizes, test on strictly larger ones (size extrapolation).
- **Baselines:** 13.2.4's learned heuristic with GBFS (search-based); h_FF GBFS; random applicable actions.
- **Expected metric:** success rate without search, plan length relative to h_FF GBFS, and wall time. Hypothesis: on VisitAll and Gripper both learned planners solve ≥ 90% of larger instances with near-GBFS plan lengths and no search; on Logistics-lite both fail under size extrapolation (as the paper reports), where the learned heuristic with search still succeeds.
- **Source:** [arXiv:2602.23148](https://arxiv.org/abs/2602.23148)

### 13.2.7 Constraint satisfaction: backtracking with MRV/degree/LCV, forward checking, AC-3 and MAC, and min-conflicts local search (Mackworth, AIJ 1977; Haralick & Elliott, AIJ 1980; Minton et al., AIJ 1992)
A CSP has variables with finite domains and constraints. Backtracking search improves greatly with variable ordering (minimum remaining values with a degree tie-break), value ordering (least constraining value) and propagation: forward checking prunes neighbours' domains, AC-3 enforces arc consistency, and maintaining arc consistency (MAC) does it at every node. Conflict-directed backjumping returns to the cause of a dead end. Min-conflicts local search repeatedly reassigns a conflicted variable to its least-conflicting value and solves million-queens instances.
- **Block:** `experimental.logic.ConstraintSolver` (BT, FC, MAC, CBJ; MRV, DEG, LCV; AC3) and `experimental.logic.MinConflicts` (with tabu and random walk).
- **Experiment:** `experiments.symbolic.ConstraintSolving`.
- **Toy task:** `ConstraintInstances` N-queens (8–200), graph colouring, Model-RB random CSPs swept across the phase transition, 9×9 Sudoku.
- **Baselines:** the CNF encoding solved by `RandomSatFormulas`' DPLL and by wave 11's `LearnedWalkSat` WalkSAT; plain chronological backtracking.
- **Expected metric:** solve rate, nodes and time, with the cost peak at the phase transition. Hypothesis: MAC + MRV solves every Sudoku with fewer than 50 nodes; min-conflicts solves 200-queens in under 1000 steps where complete search needs far more; all complete methods peak at the phase transition, where MAC's advantage over FC is largest; DPLL on the CNF encoding is 10–100× slower than MAC on Sudoku.
- **Source:** Mackworth, "Consistency in networks of relations" (AIJ 1977); Minton et al., "Minimizing conflicts" (AIJ 1992).

### 13.2.8 ANYCSP: a GNN as a global search heuristic for any CSP (Tönshoff, Kisin, Lindner & Grohe, IJCAI 2023)
ANYCSP encodes any CSP as one graph of variables, values and constraints, so one GNN handles every arity and domain size. At each step of a stochastic search it outputs a distribution over the values of every variable and can change any number of variables at once (a global action space), keeping the best assignment seen. It is trained without labels by policy gradient on random instances, with a reward for reducing conflicts relative to the best so far.
- **Block:** `experimental.logic.AnyCsp` (constraint–value graph, recurrent GNN, global sampling, REINFORCE training with a baseline).
- **Experiment:** `ConstraintSolving` (learned table).
- **Toy task:** graph colouring (3-COL on random graphs near the threshold), Model-RB CSPs and MAX-2-SAT from `ConstraintInstances`; train on small instances, test on 2–4× larger.
- **Baselines:** 13.2.7's min-conflicts with tabu; `LearnedWalkSat` and `NeuroSat` on the CNF encodings; MAC for satisfiable-instance completeness.
- **Expected metric:** solved share and unsatisfied constraints after a fixed step budget, and size generalisation. Hypothesis: ANYCSP beats min-conflicts on 3-COL at the threshold and generalises to 2× larger graphs; MAC remains better on Sudoku-like tightly constrained instances; NeuroSAT (a decision classifier) is far behind as a solver.
- **Source:** [arXiv:2208.10227](https://arxiv.org/abs/2208.10227)

### 13.2.9 Conflict-driven clause learning: 1-UIP learning, watched literals, VSIDS, restarts and phase saving (Marques-Silva & Sakallah, IEEE TC 1999; Moskewicz et al., DAC 2001; Eén & Sörensson, SAT 2003)
CDCL extends DPLL: on a conflict it analyses the implication graph to the first unique implication point, learns the resulting clause, and backjumps non-chronologically. Two watched literals per clause make unit propagation cheap; VSIDS bumps the activity of variables in recent conflicts and decays the rest; Luby restarts with phase saving and learnt-clause deletion by activity or LBD keep the search focused. The block is a compact MiniSat-style solver that also logs per-run costs (decisions, propagations, conflicts) for 13.2.10 and 13.2.16.
- **Block:** `experimental.logic.CdclSolver` (watched literals, 1-UIP, VSIDS, Luby and glucose-style restarts, phase saving, LBD-based clause deletion; hooks for external variable weights and polarities).
- **Experiment:** `experiments.symbolic.SatSolving`.
- **Toy task:** `RandomSatFormulas` 3-SAT at ratio 4.26 (n = 50–250), pigeonhole (unsat), graph-colouring CNFs and planning encodings from `ConstraintInstances`.
- **Baselines:** `RandomSatFormulas`' DPLL; `LearnedWalkSat`'s WalkSAT (satisfiable instances only); `NeuroSat` as a SAT/UNSAT classifier.
- **Expected metric:** solved share within a conflict budget, time, conflicts; each feature switched off in turn (ablation). Hypothesis: CDCL solves 250-variable random 3-SAT in tens of milliseconds where DPLL times out beyond ~120 variables; on structured colouring and planning instances clause learning and VSIDS each give ≥ 10× speed-ups; WalkSAT wins on large satisfiable random instances and cannot prove unsatisfiability; pigeonhole stays exponential for all of them.
- **Source:** Marques-Silva & Sakallah, "GRASP" (IEEE TC 1999); Eén & Sörensson, "An extensible SAT-solver" (SAT 2003).

### 13.2.10 RLAF: one-shot GNN guidance of a SAT solver trained by reinforcement learning from algorithm feedback (Tönshoff & Grohe, May 2025)
Rather than replacing the solver's branching heuristic, a GNN reads the formula's literal–clause graph once and outputs, for every variable, the parameters of a log-normal weight and a Bernoulli polarity. Sampled weights scale the solver's own branching scores (VSIDS here) and polarities set the first value tried. The GNN is trained by policy gradient (GRPO) with the solver's cost as the only reward, so no expert labels are needed; the paper reports > 2× mean speed-ups that generalise to larger instances and beat supervised weighting baselines.
- **Block:** `experimental.logic.RlafGuidance` (literal–clause GNN reusing `NeuroSat`'s message passing where possible, log-normal/Bernoulli heads, group-relative policy gradient over k samples per formula) plugged into 13.2.9's weight and polarity hooks.
- **Experiment:** `SatSolving` (guidance table).
- **Toy task:** 3-SAT and graph-colouring CNFs from `ConstraintInstances` (n = 50–100 for training, 150–250 for testing), satisfiable and unsatisfiable mixed.
- **Baselines:** plain CDCL with VSIDS (13.2.9); a supervised weighting baseline that predicts backbone/core membership from `NeuroSat` embeddings (NeuroCore-style); random weights.
- **Expected metric:** mean and median solver cost (decisions/conflicts) relative to plain CDCL, on training-size and larger instances. Hypothesis: RLAF lowers mean conflicts by 20–50% on in-distribution colouring CNFs and keeps a gain on 2× larger instances; on random 3-SAT the gain is small; the supervised weighting gives less than RLAF.
- **Source:** [arXiv:2505.16053](https://arxiv.org/abs/2505.16053)

### 13.2.11 Knowledge compilation and weighted model counting: OBDDs and decision-DNNF by component caching (Bryant, IEEE TC 1986; Darwiche, JAIR 2002; Sang, Beame & Kautz, AAAI 2005; Chavira & Darwiche, AIJ 2008)
Compiling a constraint into a tractable circuit makes repeated queries cheap: once compiled, model counting, weighted model counting (WMC) and conditioning are linear in the circuit. Reduced ordered BDDs are canonical but order-sensitive; decision-DNNF from an exhaustive DPLL trace with component decomposition and caching is exponentially more succinct on many problems. Encoding a Bayesian network as weighted CNF and computing WMC gives exact inference that exploits determinism and context-specific independence, which variable elimination does not.
- **Block:** `experimental.logic.KnowledgeCompiler` (OBDD with min-fill or static orderings; DECISION_DNNF by exhaustive DPLL with components and caching; WMC and gradient of WMC with respect to literal weights).
- **Experiment:** `experiments.symbolic.LogicInference` (compilation table).
- **Toy task:** exactly-k and Latin-square constraints (the cases `SemanticLoss` handles in closed form) plus constraints it cannot handle (paths in a grid, simple-path and hierarchy constraints); Bayesian networks with deterministic CPTs from `ConstraintInstances`.
- **Baselines:** `SemanticLoss`'s closed forms; `FactorGraph` variable elimination and loopy BP; brute-force enumeration for tiny sizes.
- **Expected metric:** circuit size and compile time, query time, exactness against enumeration; semantic-loss training with compiled constraints on a grid-path task (path validity of predictions). Hypothesis: decision-DNNF is ≥ 10× smaller than the OBDD on grid-path constraints; WMC matches variable elimination exactly and is faster when CPTs are deterministic; semantic loss with the compiled path constraint raises valid-path rate from < 0.3 to > 0.7 over a plain MLP.
- **Source:** Darwiche, "A compiler for deterministic, decomposable negation normal form" (AAAI 2002); Chavira & Darwiche, "On probabilistic inference by weighted model counting" (AIJ 2008).

### 13.2.12 Saturation-based theorem proving with learned clause selection (Robinson, JACM 1965; McCune, Otter/Prover9; Jakubův & Urban, CICM 2017; Loos et al., LPAR 2017)
A resolution prover saturates a clause set (the negated conjecture plus axioms) by the given-clause loop: pick a clause from the passive set, move it to the active set, and add its resolvents and factors (with most general unifiers) to the passive set, discarding tautologies and subsumed clauses, until the empty clause appears. Which clause to pick dominates performance; provers mix age and symbol-count (weight) queues. ENIGMA learns a classifier over clause features from previous proofs that predicts whether a clause appears in a proof, and uses it to rank the passive set.
- **Block:** `experimental.logic.ResolutionProver` (first-order clauses with unification and occurs check, binary resolution, factoring, forward/backward subsumption, given-clause loop; selection AGE, WEIGHT, AGE_WEIGHT, LEARNED) and `experimental.logic.ClauseSelector` (ENIGMA-style feature hashing with logistic regression or a small MLP).
- **Experiment:** `LogicInference` (proving table).
- **Toy task:** generated first-order problems from `ConstraintInstances`: family-relation theorems over `FamilyTreeGraph`-style axioms, transitive-closure and equivalence-relation lemmas, propositional pigeonhole for small n, and group-theory identities over a fixed axiom set (equality via axioms).
- **Baselines:** AGE and WEIGHT selection; `DifferentiableIlp` for the family tasks (learning the rule rather than proving it); CDCL (13.2.9) on propositional instances.
- **Expected metric:** proved share within a given-clause budget, given clauses processed per proof. Hypothesis: AGE_WEIGHT beats either pure queue; the learned selector trained on proofs of small problems proves 20–40% more held-out problems at the same budget and halves processed clauses on the ones both prove.
- **Source:** Jakubův & Urban, "ENIGMA: Efficient learning-based inference guiding machine" (CICM 2017); Loos et al., "Deep network guided proof search" (LPAR 2017).

### 13.2.13 Markov logic networks: grounding, MC-SAT inference and pseudo-likelihood weight learning (Richardson & Domingos, MLJ 2006; Poon & Domingos, AAAI 2006; Lowd & Domingos, ECML 2007)
A Markov logic network attaches a weight to each first-order formula; grounding it over a set of constants gives a Markov random field in which a world's log-probability is the weighted count of satisfied groundings. Inference by Gibbs sampling mixes poorly with near-deterministic formulas; MC-SAT is a slice sampler that, at each step, samples nearly uniformly from the satisfying assignments of a random subset of currently satisfied clauses (with a SampleSAT-style walk), and handles determinism. Weights are learned by maximising pseudo-log-likelihood or by diagonal-Newton on the likelihood with MC-SAT expectations.
- **Block:** `experimental.logic.MarkovLogic` (formula templates over binary/unary predicates, grounding, GIBBS, MC_SAT, MAP by MaxWalkSAT, PSEUDO_LIKELIHOOD and DIAGONAL_NEWTON learning).
- **Experiment:** `LogicInference` (MLN table).
- **Toy task:** "friends and smokers" social networks on `SyntheticGraphs` (Smokes(x) ∧ Friends(x,y) ⇒ Smokes(y), Smokes ⇒ Cancer), family relations from `FamilyTreeGraph` with a hard transitivity rule, with 30–60% of query atoms hidden.
- **Baselines:** the grounded network in `FactorGraph` with Gibbs and loopy BP (same model, generic inference); `NeuralPredicateProgram`-style exact proof enumeration on tiny worlds; logistic regression on hand-built relational features.
- **Expected metric:** query-atom AUROC and conditional log-likelihood, and samples to converge with deterministic rules. Hypothesis: MC-SAT matches exact marginals on tiny worlds and beats Gibbs and loopy BP on worlds with hard rules (Gibbs gets stuck); pseudo-likelihood learning recovers the planted weights' signs and is 10× faster than likelihood learning, with lower CLL; MLN beats the feature-based logistic baseline when relations matter.
- **Source:** Richardson & Domingos, "Markov logic networks" (MLJ 2006); Poon & Domingos, "Sound and efficient inference with probabilistic and deterministic dependencies" (AAAI 2006).

### 13.2.14 Answer set programming: grounding, Clark completion with loop formulas and stable models by CDCL (Gelfond & Lifschitz, ICLP 1988; Lin & Zhao, AIJ 2004; Gebser et al., AIJ 2012)
Answer set programming describes problems as normal logic programs with default negation, choice rules and integrity constraints; solutions are stable models. A stable model of a tight program is a model of its Clark completion, so a SAT solver finds it; for non-tight programs (positive recursion, such as reachability) loop formulas must be added lazily when an unfounded set is found, as clasp does inside conflict-driven search. The block grounds small programs with a semi-naive bottom-up grounder, builds the completion, and adds loop formulas on demand inside 13.2.9's CDCL.
- **Block:** `experimental.logic.AnswerSetSolver` (rule representation, semi-naive grounding, completion, unfounded-set check and loop-formula learning, choice rules and cardinality constraints by sequential counters; model enumeration).
- **Experiment:** `LogicInference` (ASP table).
- **Toy task:** graph colouring, Hamiltonian cycle on small graphs (needs reachability: non-tight), N-queens and a blocks-planning program with a time horizon.
- **Baselines:** 13.2.7's MAC solver on the CSP versions; a direct CNF encoding solved by 13.2.9; plain completion without loop formulas (which admits unsupported "models").
- **Expected metric:** correct-model rate, time to first model and to enumerate all models, grounding size. Hypothesis: plain completion returns invalid Hamiltonian cycles (disjoint sub-cycles) on most instances, loop formulas fix all of them with a small number of added clauses; on tight problems ASP is within 2–3× of the direct CNF encoding.
- **Source:** Lin & Zhao, "ASSAT: computing answer sets of a logic program by SAT solvers" (AIJ 2004); Gebser, Kaufmann & Schaub, "Conflict-driven answer set solving" (AIJ 2012).

### 13.2.15 Neuro-fuzzy inference: Mamdani and Takagi–Sugeno systems and ANFIS (Mamdani & Assilian, 1975; Takagi & Sugeno, IEEE SMC 1985; Jang, IEEE SMC 1993)
A fuzzy inference system maps inputs through membership functions (Gaussian or bell) to rule firing strengths (product t-norm) and combines rule consequents: Mamdani rules have fuzzy-set consequents defuzzified by centroid, Takagi–Sugeno rules have linear consequents averaged by normalised firing strength. ANFIS writes a first-order TS system as a five-layer network and trains it by a hybrid rule: least squares for the linear consequents in the forward pass and gradient descent for the membership parameters in the backward pass. Rule bases are initialised by grid partition or subtractive clustering.
- **Block:** `experimental.logic.FuzzyInference` (MAMDANI, TAKAGI_SUGENO; membership families; grid and subtractive-clustering initialisation) and `experimental.logic.Anfis` (hybrid LS + GD learning via core `LeastSquares.ols` and autograd).
- **Experiment:** `experiments.symbolic.FuzzyInference`.
- **Toy task:** Mackey–Glass one-step-ahead prediction (`ChaoticSeries`, the original ANFIS benchmark), a 2-D nonlinear function (sinc), and a control surface (the cart-pole PD law from `CartPole`).
- **Baselines:** an MLP with equal parameter count; `KanLayer` (KAN, also spline-based and interpretable); RBF-feature ridge (`RandomFourierFeatures` or Gaussian RBFs); `ExplainableBoosting` for the 2-D task.
- **Expected metric:** test RMSE, parameter count, number of rules; training time. Hypothesis: ANFIS with 16 rules reaches Mackey–Glass RMSE comparable to the MLP at ~10× fewer epochs thanks to the LS step; on sinc it beats the MLP at equal parameters; KAN matches it; grid partition explodes with input dimension where subtractive clustering keeps the rule count small.
- **Source:** Jang, "ANFIS: adaptive-network-based fuzzy inference system" (IEEE SMC 1993).

### 13.2.16 Planning as satisfiability with incremental horizons (Kautz & Selman, ECAI 1992 and AAAI 1996; Rintanen, AIJ 2012)
SATPlan encodes "is there a plan of length T?" as CNF with one variable per fact and action per time step (frame axioms, preconditions, effects, and action mutexes, either sequential or ∀-step parallel), and increases T until the formula is satisfiable; the first satisfying T gives a makespan-optimal parallel plan. Rintanen's ∃-step semantics and evaluating several horizons in parallel make it competitive with heuristic search on some domains.
- **Block:** `experimental.symbolic.SatPlanner` (SEQUENTIAL, FORALL_STEP, EXISTS_STEP encodings; linear and doubling horizon schedules) using 13.2.9's CDCL; the CNFs also feed `ConstraintInstances`.
- **Experiment:** `SatSolving` (planning table).
- **Toy task:** `PlanningDomains` Gripper, Logistics-lite and Blocksworld.
- **Baselines:** 13.2.1's GBFS with h_FF and A* with h_max (13.2.2's LM-cut for optimal sequential length); `RandomSatFormulas`' DPLL on the same CNF.
- **Expected metric:** coverage, time, makespan and sequential plan length. Hypothesis: ∀-step SATPlan finds makespan-optimal plans on Logistics-lite faster than optimal A* finds length-optimal ones, while GBFS h_FF is fastest overall but not optimal; DPLL on the same CNFs times out beyond the smallest instances, showing that the encoding needs CDCL.
- **Source:** Kautz & Selman, "Pushing the envelope: planning, propositional logic and stochastic search" (AAAI 1996); Rintanen, "Planning as satisfiability: heuristics" (AIJ 2012).

### 13.3.1 Variational quantum eigensolver with hardware-efficient and Hamiltonian-variational ansätze (Peruzzo et al., Nature Communications 2014; Kandala et al., Nature 2017; Wiersema et al., PRX Quantum 2020)
VQE minimises the energy ⟨ψ(θ)|H|ψ(θ)⟩ of a parametrised circuit, measuring H as a sum of Pauli strings; gradients come from the parameter-shift rule or, in simulation, the adjoint method. Hardware-efficient ansätze (rotation layers and CNOT rings) are expressive but suffer barren plateaus; the Hamiltonian variational ansatz alternates exponentials of the Hamiltonian's non-commuting terms, respecting its symmetries, and trains well at moderate depth. Finite measurement shots add noise that optimisers such as SPSA tolerate.
- **Block:** `experimental.quantum.StateVector` (gates, Pauli-string expectations, adjoint gradients; shares conventions with `QuantumCircuitLayer`), `experimental.quantum.PauliHamiltonian` and `experimental.quantum.Vqe` (HARDWARE_EFFICIENT, HAMILTONIAN_VARIATIONAL; Adam, L-BFGS via `Optimizer.minimize`, SPSA; exact or shot-noise expectations).
- **Experiment:** `experiments.science.QuantumAlgorithms`.
- **Toy task:** `SpinModels` transverse-field Ising chain (N = 6–10) across h/J ∈ {0.5, 1, 2} and the Heisenberg XXZ chain; exact energies from `Matrices.lanczos`.
- **Baselines:** exact diagonalisation; the mean-field product state; `QuantumCircuitLayer`'s hardware-efficient ansatz and parameter-shift gradients (its own read-out, reused for the circuit structure).
- **Expected metric:** relative energy error and fidelity with the exact ground state against depth, circuit evaluations, and gradient variance at initialisation. Hypothesis: the Hamiltonian variational ansatz reaches relative error < 1e-3 at depth ~N/2 at the critical point h = J, where the hardware-efficient ansatz stalls above 1e-2 with vanishing gradient variance; SPSA with 1000 shots reaches ~1e-2.
- **Source:** [arXiv:1304.3061](https://arxiv.org/abs/1304.3061) (VQE); Wiersema et al., "Exploring entanglement and optimization within the Hamiltonian variational ansatz" (PRX Quantum 2020).

### 13.3.2 QAOA for MaxCut with parameter transfer and interpolation (Farhi, Goldstone & Gutmann, 2014; Zhou et al., PRX 2020)
QAOA alternates p layers of the cost unitary exp(−iγC) and the mixer exp(−iβΣX) from |+⟩ⁿ and maximises ⟨C⟩ over the 2p angles; the approximation ratio improves with p. Optimising from random angles finds poor local optima as p grows; the INTERP heuristic initialises depth p+1 by interpolating the optimal depth-p schedule, and angles transfer well between random regular graphs of the same degree.
- **Block:** `experimental.quantum.Qaoa` (MaxCut cost diagonal, exact simulation, RANDOM, INTERP, FOURIER and transferred initialisations; optimisation by `Optimize.nelderMead` or L-BFGS; sampling of cuts).
- **Experiment:** `QuantumAlgorithms` (QAOA table).
- **Toy task:** MaxCut on 3-regular and Erdős–Rényi graphs with n = 8–12 from `SyntheticGraphs` / `SpinModels`; exact optimum by enumeration.
- **Baselines:** classical solvers already in the repo on the same instances: `ProbabilisticBits` and `SimulatedBifurcation` Ising machines, wave 11's `ClassicHeuristics` (greedy and local search); random cuts (ratio 0.5).
- **Expected metric:** approximation ratio ⟨C⟩/C_max and probability of sampling an optimal cut against p, and optimiser evaluations. Hypothesis: with INTERP initialisation the ratio rises monotonically to ≥ 0.9 at p = 5 on 3-regular graphs, while random initialisation plateaus; transferred angles from n = 8 reach within 0.01 of re-optimised ones at n = 12; the classical Ising machines find optimal cuts on every instance at this size, the honest comparison.
- **Source:** [arXiv:1411.4028](https://arxiv.org/abs/1411.4028); Zhou et al., "Quantum approximate optimization algorithm: performance, mechanism and implementation on near-term devices" (PRX 2020).

### 13.3.3 Neural-network quantum states with variational Monte Carlo and stochastic reconfiguration (Carleo & Troyer, Science 2017; Sorella, PRL 1998)
A neural network ψ_θ(σ) gives the (log-)amplitude of every spin configuration; variational Monte Carlo samples σ ∝ |ψ|² by Metropolis, estimates the energy from local energies E_loc(σ) = Σ_σ' H_σσ' ψ(σ')/ψ(σ), and follows the gradient. Stochastic reconfiguration (imaginary-time evolution projected onto the ansatz, equivalent to natural gradient with the quantum geometric tensor S) preconditions the gradient by solving (S + λI)δ = −f, which is far more stable than plain gradient descent. The RBM ansatz of Carleo and Troyer and a Jastrow ansatz are the classic choices.
- **Block:** `experimental.quantum.NeuralQuantumState` (RBM, JASTROW, small MLP; Metropolis with local flips and exchange moves; local energies for Pauli Hamiltonians) and `experimental.quantum.VariationalMonteCarlo` (SGD, ADAM, STOCHASTIC_RECONFIGURATION with diagonal shift via `Matrices.cholesky`; exact-sum mode for N ≤ 12 to separate sampling error from ansatz error).
- **Experiment:** `experiments.science.QuantumStates`.
- **Toy task:** `SpinModels` TFIM chain (N = 10–12, h ∈ {0.5, 1, 2}), Heisenberg chain with the Marshall sign rule; exact energies from Lanczos.
- **Baselines:** exact diagonalisation; mean-field product state; 13.3.1's VQE at matched parameter count (a different model class for the same task).
- **Expected metric:** relative energy error, variance of local energies, and steps to converge. Hypothesis: RBM with α = 2 and SR reaches relative error ≤ 1e-3 on TFIM at h = 1 in a few hundred steps, while Adam on the same ansatz stalls around 1e-2; energy variance falls by ≥ 10× with SR; exact-sum and sampled runs agree within the sampling error.
- **Source:** [arXiv:1606.02318](https://arxiv.org/abs/1606.02318)

### 13.3.4 Foundation neural quantum states across Hamiltonian couplings, with fidelity susceptibility for phase transitions (Rende et al., Aug 2025)
Instead of training one NQS per coupling value, a single network takes both the spin configuration and the couplings as input, ψ_θ(σ; h), and is trained on many couplings at once by stochastic reconfiguration on an ensemble-averaged objective. Because ψ depends explicitly on h, the fidelity susceptibility χ_F(h) (the curvature of the overlap between neighbouring ground states) can be computed by automatic differentiation, which locates phase transitions without an order parameter. The 2025 paper uses a ViT ansatz on large lattices; here the conditioning is tested at toy scale.
- **Block:** `experimental.quantum.ConditionalQuantumState` (coupling-conditioned MLP/RBM with FiLM-style conditioning, ensemble SR over sampled couplings, χ_F via autograd).
- **Experiment:** `QuantumStates` (foundation table).
- **Toy task:** TFIM chain N = 10 with h ∈ [0.2, 2.0] (critical point h = 1); a disordered variant with random couplings; exact χ_F from Lanczos ground states at neighbouring h.
- **Baselines:** independent per-h NQS from 13.3.3 at the same total optimisation steps; exact diagonalisation.
- **Expected metric:** mean relative energy error over a grid of h (including values not seen in training), total cost, and the location of the χ_F peak. Hypothesis: the conditional model matches per-h models' accuracy within 2× error at a quarter of the total steps and interpolates to unseen h; its χ_F peaks within 0.1 of the exact finite-size peak.
- **Source:** [arXiv:2502.09488](https://arxiv.org/abs/2502.09488)

### 13.3.5 Quantum state tomography: linear inversion, maximum likelihood, neural-network tomography and classical shadows (Hradil, PRA 1997; Torlai et al., Nature Physics 2018; Huang, Kueng & Preskill, Nature Physics 2020)
Tomography reconstructs a state from measurement outcomes in random Pauli bases. Linear inversion is unbiased but gives unphysical density matrices; maximum likelihood by the RρR fixed-point iteration enforces positivity; neural-network tomography fits an RBM wavefunction to measurement records (scaling to more qubits for pure states); classical shadows skip reconstruction and predict many observables (local Paulis, fidelities) from randomised single-qubit measurements with sample complexity logarithmic in their number.
- **Block:** `experimental.quantum.Tomography` (LINEAR_INVERSION, MLE_RRHO, NEURAL_RBM, CLASSICAL_SHADOWS with median-of-means) using 13.3.1's `StateVector` for measurement simulation.
- **Experiment:** `QuantumStates` (tomography table).
- **Toy task:** `SpinModels` GHZ, W, random product and TFIM ground states for 3–8 qubits; 10²–10⁵ measurement shots.
- **Baselines:** linear inversion; direct estimation of each observable from its own measurement basis (the naive protocol shadows replace).
- **Expected metric:** infidelity of the reconstructed state against shots, and the maximum error over all 2-local Pauli expectations. Hypothesis: MLE beats linear inversion at low shots and is always physical; the RBM reaches infidelity < 0.05 for 8-qubit GHZ where full MLE becomes slow; classical shadows estimate all 2-local observables with error ≤ 0.05 using ~10× fewer shots than measuring each basis separately.
- **Source:** [arXiv:2002.08953](https://arxiv.org/abs/2002.08953) (shadows); Torlai et al., "Neural-network quantum state tomography" (Nature Physics 2018).

### 13.3.6 Flow-based MCMC for lattice φ⁴ field theory (Albergo, Kanwar & Shanahan, PRD 2019; Nicoli et al., PRL 2021)
Near a critical point, local Metropolis and HMC updates of a lattice field decorrelate slowly (critical slowing down). A normalising flow trained by reverse KL to the Boltzmann weight e^{−S(φ)} proposes whole configurations; an independence Metropolis–Hastings step with acceptance min(1, p(φ')q(φ)/p(φ)q(φ')) makes the chain exact, and the effective sample size of the importance weights measures the flow's quality. Affine coupling layers with checkerboard masks respect locality; translation-equivariant convolutional couplings generalise across volumes.
- **Block:** `experimental.science.LatticePhi4` (action, magnetisation, susceptibility, local Metropolis) and `experimental.science.FlowSampler` (checkerboard RealNVP with small CNN couplings, reverse-KL training, independence MH, ESS), reusing `experimental.nn.DensityFlow`/`GlowFlow` building blocks where they fit.
- **Experiment:** `experiments.science.LatticeSampling`.
- **Toy task:** 2-D φ⁴ on 6×6 and 8×8 lattices with κ swept through the symmetric, critical and broken phases (Albergo et al.'s parameterisation).
- **Baselines:** local Metropolis (in the block, as the physics baseline) and `experimental.train.HamiltonianMonteCarlo` on the field; plain importance sampling from a Gaussian.
- **Expected metric:** integrated autocorrelation time of |M| per independent-proposal step and per unit of wall time, ESS per sample, acceptance rate. Hypothesis: near criticality the flow sampler's autocorrelation time is ≥ 10× shorter than HMC's per step at 6×6, with acceptance ≥ 0.4; at 8×8 acceptance falls (the known scaling problem), shrinking the advantage.
- **Source:** [arXiv:1904.12072](https://arxiv.org/abs/1904.12072)

### 13.3.7 Epidemic inference: SEIR fitting, renewal-equation Rₜ estimation and nowcasting reporting delays (Kermack & McKendrick, 1927; Cori et al., AJE 2013; Abbott et al., Wellcome Open Res. 2020)
Compartmental models (SIR, SEIR) are fitted to case counts by Poisson or negative-binomial likelihood over the ODE solution. The renewal equation I_t = R_t Σ_s w_s I_{t−s} with a known serial-interval distribution w gives the time-varying reproduction number; EpiEstim's conjugate gamma posterior over a sliding window is the standard estimator, and a random-walk prior on log Rₜ with a Kalman or particle filter is the smooth alternative. Reporting delays bias the most recent counts down; nowcasting corrects them with a delay distribution estimated from reporting triangles.
- **Block:** `experimental.science.Epidemics` (SIR/SEIR ODE with Poisson/NB likelihood fitted by `Optimize.nelderMead` and L-BFGS, profile-likelihood intervals; EPIESTIM, RW_KALMAN, RW_PARTICLE Rₜ; delay nowcast by a multinomial chain-ladder).
- **Experiment:** `experiments.science.Epidemics`.
- **Toy task:** `ScienceSims` stochastic SEIR outbreaks with a step change and a smooth change in Rₜ (an intervention), with reporting delays and under-ascertainment.
- **Baselines:** `Arima` and `ExponentialSmoothing` forecasts of case counts; `UniversalDifferentialEquation` (an SIR with a neural transmission term) as the learned dynamics baseline; `EnsembleKalmanFilter` on the SEIR state.
- **Expected metric:** Rₜ RMSE and 90% interval coverage, 7- and 14-day forecast WIS/MAE, and peak-timing error; nowcast error of the last 7 days. Hypothesis: EpiEstim tracks step changes with a window-length lag, the random-walk filter tracks smooth changes better; the mechanistic SEIR beats ARIMA/ETS at 14 days around the peak and loses on short horizons in the tail; nowcasting removes most of the downward bias in the last week.
- **Source:** Cori et al., "A new framework and software to estimate time-varying reproduction numbers" (AJE 2013).

### 13.3.8 PINN-pretrained SIR surrogate with rolling-window MCMC for forecasting (Rama et al., 2025–26)
A physics-informed network is trained once on many synthetic SIR epidemics with the SIR equations in its loss, so that it maps (t; β, γ, τ₀) to the epidemic curve. For a real season it is never retrained: β, γ and a time offset τ₀ are inferred by MCMC on a rolling five-week window with a Poisson likelihood, using the network as a fast surrogate for the ODE. The paper reports four-week-ahead forecasts competitive with state-of-the-art approaches on Italian influenza data, with stable β estimates but undercovering intervals.
- **Block:** `experimental.science.SirSurrogate` (parametric PINN via `PhysicsInformedNetwork`'s residual machinery, trained over a prior box of (β, γ, τ₀)) plus rolling-window inference with `HamiltonianMonteCarlo` or random-walk Metropolis.
- **Experiment:** `Epidemics` (surrogate table).
- **Toy task:** `ScienceSims` seasonal SIR-like waves with weekly counts, reporting noise and a mild model mismatch (SEIR truth).
- **Baselines:** 13.3.7's direct ODE fit with MCMC (same likelihood, exact solver); `Arima`; a plain MLP surrogate trained on simulated curves without the physics loss.
- **Expected metric:** 4-week-ahead MAE and WIS, 50%/90% interval coverage, and wall time per window. Hypothesis: the surrogate matches the direct ODE fit's forecast error at ≥ 10× less time per window; both beat ARIMA at 3–4 weeks; the non-physics surrogate extrapolates worse outside the prior box; intervals undercover under mismatch, as the paper notes.
- **Source:** [arXiv:2506.03897](https://arxiv.org/abs/2506.03897)

### 13.3.9 Ecology with imperfect detection: capture–recapture (Lincoln–Petersen, Schnabel, Cormack–Jolly–Seber) and site-occupancy models (Seber, 1982; MacKenzie et al., Ecology 2002)
Counting animals underestimates abundance because detection is imperfect. Capture–recapture estimates population size from marked and recaptured individuals (Lincoln–Petersen with Chapman's correction for two occasions, Schnabel for several, the CJS model for survival in open populations by maximum likelihood). Occupancy models separate the probability that a site is occupied (ψ) from the probability of detecting the species when present (p), using repeated visits, by maximising a zero-inflated binomial likelihood with logistic covariates.
- **Block:** `experimental.science.CaptureRecapture` (LINCOLN_PETERSEN, CHAPMAN, SCHNABEL, CJS) and `experimental.science.OccupancyModel` (single-season ψ(x) p(w) by L-BFGS; Royle–Nichols abundance-induced heterogeneity).
- **Experiment:** `experiments.science.Ecology`.
- **Toy task:** `ScienceSims` capture histories (N = 100–1000, p = 0.1–0.5, survival 0.6–0.9) and occupancy surveys (200 sites, 2–5 visits, covariate effects on ψ and p).
- **Baselines:** naive counts (number of distinct animals seen; naive occupancy = share of sites with a detection); logistic regression of detection on covariates ignoring imperfect detection (a `PenalizedRegression` logistic fit); `RandomForest` classifier on site covariates.
- **Expected metric:** relative bias and 95% CI coverage of N̂ and ψ̂, and covariate-effect error. Hypothesis: naive estimates are biased by the detection probability (−30 to −70% at p = 0.3), Chapman and the occupancy model are nearly unbiased with ≈ 95% coverage given ≥ 3 visits; the naive logistic model attributes detection covariates to occupancy.
- **Source:** MacKenzie et al., "Estimating site occupancy rates when detection probabilities are less than one" (Ecology 2002).

### 13.3.10 Species distribution modelling from presence-only data: MaxEnt as an inhomogeneous Poisson process (Phillips, Anderson & Schapire, Ecol. Model. 2006; Warton & Shepherd, AoAS 2010; Renner & Warton, Biometrics 2013)
MaxEnt fits a Gibbs distribution over raster cells, p(x) ∝ exp(βᵀf(x)), to presence records with feature classes (linear, quadratic, hinge, product) and ℓ1 regularisation; it is equivalent to an inhomogeneous Poisson point-process model, which can be fitted by weighted Poisson regression on presences plus quadrature background points (Berman–Turner). Presence–background logistic regression approximates it but depends on the number of background points. Sampling bias (more records near roads) is corrected by a bias covariate set to a constant at prediction.
- **Block:** `experimental.science.SpeciesDistribution` (MAXENT with hinge/product features and ℓ1 via wave 12's `stats.PenalizedRegression`, IPP by Berman–Turner quadrature, PRESENCE_BACKGROUND logistic, bias-covariate correction).
- **Experiment:** `Ecology` (distribution table).
- **Toy task:** `ScienceSims` 64×64 rasters with 4–6 covariates, a true intensity λ(x), presences sampled with and without road-like sampling bias, and presence–absence test surveys.
- **Baselines:** `RandomForest` and core `GradientBoostedTrees` on presence vs background; `GaussianProcess` classification on a subsample; a kernel density estimate of presence locations (no covariates).
- **Expected metric:** test AUROC on presence–absence surveys, correlation of the predicted and true intensity maps, and sensitivity to the number of background points. Hypothesis: MaxEnt/IPP match each other and beat KDE and unregularised logistic models; presence–background logistic converges to IPP only with many background points; bias correction raises map correlation from ~0.5 to ~0.8 under road bias; tree ensembles rank well (AUROC) but give poorly scaled intensities.
- **Source:** Renner & Warton, "Equivalence of MAXENT and Poisson point process models for species distribution modeling in ecology" (Biometrics 2013).

### 13.3.11 Rainfall–runoff modelling: the HBV conceptual model, LSTMs and differentiable δ-HBV hybrids under warming (Bergström, 1976; Kratzert et al., HESS 2018; Feng et al., WRR 2022; Bohl et al., HESS 2026)
HBV routes precipitation through snow, soil-moisture and two groundwater buckets with ~12 parameters, calibrated per catchment (here by `Optimize.cmaEs`). LSTMs trained on meteorological forcings beat calibrated conceptual models on Nash–Sutcliffe efficiency. Differentiable hybrids (δ-HBV) let an LSTM produce HBV's parameters (static or time-varying) and train end-to-end through the bucket equations. The 2026 HESS study (918 catchments, cold-period training, warm-period testing) finds the LSTM most accurate but least robust to warming, and the hybrid best at reproducing observed change signals.
- **Block:** `experimental.science.Hbv` (snow, soil, response routines; numpy-free daily stepping; differentiable `Var` version) and `experimental.science.HybridHydrology` (LSTM via core `Recurrent.lstm`, DELTA_HBV with static or dynamic parameters).
- **Experiment:** `experiments.science.Hydrology`.
- **Toy task:** `ScienceSims` catchments generated by a "true" HBV with structural differences (an extra slow store) and synthetic weather; training on 10 cold years, testing on 5 warmer years (+2 °C, less snow), several catchments.
- **Baselines:** HBV calibrated by CMA-ES (the conceptual baseline, in the block) and by `Optimize.nelderMead`; `Arima` with exogenous rainfall; persistence; an MLP on lagged forcings.
- **Expected metric:** NSE and KGE on the cold test years and on the warm period, and error in the simulated change of mean and high flows. Hypothesis: LSTM has the best cold-period NSE; its NSE drops most in the warm period and it misestimates the change in snowmelt-driven flows; δ-HBV is within a few NSE points of the LSTM and reproduces the change signal best, matching the HESS 2026 ranking.
- **Source:** [HESS 30, 4667 (2026)](https://hess.copernicus.org/articles/30/4667/2026/); Kratzert et al., "Rainfall–runoff modelling using LSTM networks" (HESS 2018).

### 13.3.12 Learning DC optimal power flow: LP solution, learned dispatch with feasibility restoration, and counterfactual load repair (Pan et al., IEEE TPS 2021; Donti, Rolnick & Kolter, ICLR 2021; Mohammadian, Van Boven & Baker, 2025)
DC-OPF chooses generator outputs to meet demand at minimum cost subject to line-flow limits given by power transfer distribution factors; it is a linear program (here solved by core `Optimize.linearProgram` with equality constraints). Learning-to-optimise maps loads to dispatch with a network, but raw outputs violate limits; DeepOPF predicts a reduced set of variables and recovers the rest from power balance, and DC3 corrects with equality completion and inequality-correction gradient steps. The 2025 paper trains a feasibility classifier on load profiles and uses counterfactual explanations to propose minimal load changes that restore feasibility, checked by the solver.
- **Block:** `experimental.science.DcPowerFlow` (PTDF construction, LP formulation, feasibility check, bad-data-free WLS state estimate for the generator) and `experimental.science.LearnedOpf` (MLP_DIRECT, DEEP_OPF reduced prediction, DC3 completion and correction, FEASIBILITY_CLASSIFIER with counterfactual repair).
- **Experiment:** `experiments.science.PowerGrids`.
- **Toy task:** `ScienceSims` 9-, 14- and 30-bus synthetic grids with random load scenarios (±30%), including infeasible ones near line limits.
- **Baselines:** the LP solve (optimality reference, in the block via core `Optimize`); load shedding by LP as the feasibility-restoration baseline; WP1's 13.1.6 recourse if it has landed (otherwise `ModelAgnosticExplainer.counterfactual`) for the repair step.
- **Expected metric:** optimality gap, constraint-violation rate and magnitude, inference time vs LP time; for repair, success rate and total load change. Hypothesis: the direct MLP violates line limits on 10–30% of scenarios; DC3 and DeepOPF bring violations to ~0 with optimality gaps < 1% and are 10–100× faster than the LP; counterfactual repair restores feasibility on all infeasible cases with larger load changes than LP shedding, as the paper reports.
- **Source:** [arXiv:2504.06369](https://arxiv.org/abs/2504.06369); Donti, Rolnick & Kolter, "DC3: a learning method for optimization with hard constraints" (ICLR 2021).

### 13.3.13 Seismic phase picking: STA/LTA, AR-AIC pickers and a PhaseNet-style U-Net (Allen, BSSA 1978; Sleeman & van Eck, PEPI 1999; Zhu & Beroza, GJI 2019)
An earthquake arrival is detected when the ratio of a short-term to a long-term average of signal energy exceeds a threshold (STA/LTA); the AR-AIC picker refines onset time by finding the split point that minimises the Akaike criterion of two autoregressive models. PhaseNet trains a 1-D U-Net on three-component waveforms to output per-sample probabilities of P, S and noise, with Gaussian-shaped targets around picks, and picks peaks of the probability traces; it is far more accurate on S phases.
- **Block:** `experimental.science.PhasePicking` (STA_LTA, AR_AIC, PHASENET-lite 1-D U-Net built from `experimental.nn.UNet2d`'s conventions with height 1, peak picking).
- **Experiment:** `experiments.science.SignalSearch` (picking table).
- **Toy task:** `ScienceSims` three-component traces (100 Hz, 30 s) with P and S arrivals from synthetic sources, coloured noise and SNR from −5 to 20 dB, plus noise-only traces.
- **Baselines:** `ChangePoints` (PELT and BOCPD on energy, the repo's change-point detectors) and the CUSUM-like detectors in `AnomalySeries`; ROCKET (`RandomConvolutionFeatures`) for the trace-level detection task.
- **Expected metric:** P and S pick precision/recall within ±0.1 s, residual standard deviation, and false picks on noise. Hypothesis: STA/LTA and AR-AIC are competitive on P at high SNR and fail on S; the U-Net doubles S-pick recall at low SNR with residuals ≤ 0.05 s; PELT detects events but with onset errors ≥ 3× larger.
- **Source:** [arXiv:1803.03211](https://arxiv.org/abs/1803.03211) (PhaseNet); Allen, "Automatic earthquake recognition and timing from single traces" (BSSA 1978).

### 13.3.14 Chirp detection in coloured noise: matched filtering over a template bank against a CNN (Allen et al., PRD 2012; George & Huerta, PRD 2018; Gabbard et al., PRL 2018)
Gravitational-wave searches whiten the data by the noise spectrum and correlate it with a bank of waveform templates in the frequency domain; the maximum signal-to-noise ratio over templates, times and phases is the detection statistic, optimal for known waveforms in Gaussian noise. CNNs trained on whitened time series reproduce matched-filter sensitivity at a fraction of the cost in the papers above, but may fail on parameters outside the training range or on non-Gaussian glitches.
- **Block:** `experimental.science.MatchedFilter` (PSD estimation by averaged periodograms, whitening, FFT correlation over a template bank with placement by a minimal-match criterion, SNR time series, χ²-style glitch veto) and a small 1-D CNN detector.
- **Experiment:** `SignalSearch` (chirp table).
- **Toy task:** `ScienceSims` Newtonian inspiral chirps (two chirp-mass ranges) injected into coloured Gaussian noise and into noise with sine-Gaussian glitches, at network SNR 4–12.
- **Baselines:** an excess-power (energy) detector; ROCKET (`RandomConvolutionFeatures`) with `RidgeClassifier`; the CNN of this item is compared against the matched filter as in the papers.
- **Expected metric:** ROC (detection probability at false-alarm rate 1e-2 and 1e-3) against SNR, chirp-mass estimation error, and cost per second of data. Hypothesis: the matched filter is best on Gaussian noise inside the bank's range; the CNN reaches within 1 dB of it in Gaussian noise but degrades on chirp masses outside training; with glitches the χ² veto keeps the matched filter's false alarms down while the CNN trained without glitches false-alarms on them; ROCKET is several dB worse.
- **Source:** [arXiv:1701.00008](https://arxiv.org/abs/1701.00008) (George & Huerta); Allen et al., "FINDCHIRP" (PRD 2012).

### 13.3.15 Exoplanet transit search: box least squares and AstroNet-style CNN vetting (Kovács, Zucker & Mazeh, A&A 2002; Shallue & Vanderburg, AJ 2018)
Box least squares folds a light curve over trial periods and fits a box-shaped dip of trial duration and phase, maximising the signal residue; detrending stellar variability first (a moving median or a GP) is essential. AstroNet then classifies phase-folded "global" and "local" views of a candidate as planet or false positive (eclipsing binaries, variability) with a 1-D CNN.
- **Block:** `experimental.science.TransitSearch` (detrending by moving median or `GaussianProcess`, BLS over a period–duration grid with the fast binned algorithm, SDE significance, folding to global/local views) and `experimental.science.TransitVetter` (two-branch 1-D CNN).
- **Experiment:** `SignalSearch` (transit table).
- **Toy task:** `ScienceSims` 90-day light curves with gaps, red noise and stellar rotation, with planet transits (depth 0.05–1%, periods 1–20 d) and false positives (grazing and secondary-eclipse binaries).
- **Baselines:** a periodogram of the detrended flux (core `Fft`); `MatrixProfile` discords and `ChangePoints` for dip detection; ROCKET on the raw light curve for vetting.
- **Expected metric:** recovered-period rate (within 1%) against transit SNR; vetting AUROC and precision at 95% recall. Hypothesis: BLS recovers periods down to SNR ≈ 7 and the FFT periodogram fails on short-duty-cycle transits; GP detrending beats moving-median detrending on fast rotators; the CNN vetter reaches AUROC ≥ 0.95, several points above ROCKET on the raw curve, mostly by catching secondary eclipses in the folded views.
- **Source:** [arXiv:1712.05044](https://arxiv.org/abs/1712.05044) (AstroNet); Kovács et al., "A box-fitting algorithm in the search for periodic transits" (A&A 2002).

### 13.3.16 Neural population decoding: Wiener and Kalman filter decoders, Poisson GLMs and recurrent decoders (Wu et al., Neural Comput. 2006; Pillow et al., Nature 2008; Glaser et al., eNeuro 2020)
Brain–computer interfaces decode movement from population spike counts. The Wiener filter regresses kinematics on lagged counts; the Kalman filter decoder couples a linear-Gaussian observation model of counts given kinematics with a kinematic prior and is the classic online decoder; Poisson GLM encoding models (with spike-history terms) inverted by point-process filtering suit sparse counts; the 2020 benchmark finds LSTM/GRU decoders best given enough data. The task also measures how decoders cope with neuron drop-out and drift.
- **Block:** `experimental.science.NeuralDecoders` (WIENER, KALMAN with EM-fitted parameters, POISSON_GLM with point-process filter, RECURRENT via core `Recurrent`).
- **Experiment:** `experiments.science.Neuroscience`.
- **Toy task:** `ScienceSims` 2-D centre-out cursor trajectories driving 50–150 neurons with cosine tuning, Poisson spikes from `SpikeEncoding`-style generators, 20–50 ms bins; drift and dropout variants.
- **Baselines:** `StateSpaceFilter` / `TrackingFilters` Kalman machinery (the generic filter the decoder is built on) with naive parameters; ridge regression on the current bin; the population-vector decoder.
- **Expected metric:** R² of decoded velocity on held-out trials, against training-set size and under dropout. Hypothesis: the Kalman decoder beats Wiener and the population vector at small training sets; the GLM point-process filter wins at fine bins with low counts; the recurrent decoder overtakes both only with the largest training set, matching the benchmark; all degrade under drift, the Kalman least.
- **Source:** [arXiv:1708.00909](https://arxiv.org/abs/1708.00909) (Glaser et al.); Pillow et al., "Spatio-temporal correlations and visual signalling in a complete neuronal population" (Nature 2008).

### 13.3.17 Spike sorting: threshold detection, PCA features with GMM clustering, and template matching with overlap resolution (Lewicki, Network 1998; Quiroga, Nadasdy & Ben-Shaul, Neural Comput. 2004; Pachitariu et al., 2016)
Extracellular recordings mix spikes from several nearby neurons. The classic pipeline band-passes the trace, detects threshold crossings (at 4–5 robust noise SDs), aligns snippets, reduces them by PCA or wavelets and clusters (GMM, superparamagnetic clustering). Template-matching sorters (Kilosort-style) learn a template per unit and greedily subtract the best-matching scaled template, resolving overlapping spikes that clustering misses.
- **Block:** `experimental.science.SpikeSorting` (detection, alignment, PCA_GMM, WAVELET_GMM, TEMPLATE_MATCHING with greedy subtraction and template updating).
- **Experiment:** `Neuroscience` (sorting table).
- **Toy task:** `ScienceSims` 1–4-channel traces with 3–5 units (distinct and similar templates), refractory periods, firing-rate drift and 5–20% overlapping spikes, at several noise levels.
- **Baselines:** `GaussianMixture` and `KMeans` on raw aligned snippets; `ComponentAnalysis` PCA + `Dbscan`; wave 12's `DensityClustering` (HDBSCAN) on PCA features.
- **Expected metric:** per-unit accuracy (matched spikes within 0.5 ms), false-positive and false-negative rates, and recall on overlapping spikes; refractory-violation rate of the sorted units. Hypothesis: PCA + GMM reaches ≥ 90% accuracy on well-separated units; template matching raises recall on overlaps from < 40% to > 80%; HDBSCAN handles drift-induced non-Gaussian clusters better than GMM.
- **Source:** Quiroga, Nadasdy & Ben-Shaul, "Unsupervised spike detection and sorting with wavelets and superparamagnetic clustering" (Neural Comput. 2004).

### 13.4.1 Computed tomography: filtered back-projection, ART/SART with TV, learned primal–dual and FBPConvNet (Kak & Slaney, 1988; Andersen & Kak, 1984; Adler & Öktem, IEEE TMI 2018; Jin et al., IEEE TIP 2017)
Parallel-beam CT measures line integrals (the Radon transform). Filtered back-projection applies a ramp (Ram-Lak or Shepp–Logan) filter to each projection and back-projects; it streaks badly with few angles or noise. Algebraic methods (Kaczmarz ART, simultaneous SART) iterate projections onto the measurement hyperplanes, and adding a TV step handles sparse views. FBPConvNet post-processes FBP with a U-Net; learned primal–dual unrolls a primal–dual hybrid gradient scheme with small CNNs in both the image and the sinogram domain, using the forward and adjoint operators, and is much more accurate than post-processing.
- **Block:** `experimental.imaging.RadonTransform` (forward, adjoint, ramp filters, FBP), `experimental.imaging.AlgebraicReconstruction` (ART, SART, SART_TV) and `experimental.imaging.LearnedPrimalDual` (unrolled iterations with `Var` operators; FBP_CONVNET as the post-processing variant).
- **Experiment:** `experiments.imaging.Tomography`.
- **Toy task:** `InverseProblems` ellipse phantoms at 64×64 with 90 (full), 30 and 10 angles and Poisson-like noise.
- **Baselines:** `experimental.nn.UNet2d` on FBP (the FBPConvNet configuration); `PlugAndPlay` ADMM with a `Denoisers`/FFDNet prior adapted to the Radon operator; wave 12's `SparseRecovery` FISTA with a TV proximal step.
- **Expected metric:** PSNR/SSIM against angles, and reconstruction time. Hypothesis: FBP drops below 20 dB at 10 angles where SART-TV keeps ~26 dB; learned primal–dual beats FBPConvNet by 2–4 dB at 10–30 angles with fewer parameters and beats SART-TV at every setting; at 90 angles all methods are close.
- **Source:** [arXiv:1707.06474](https://arxiv.org/abs/1707.06474), [arXiv:1611.03679](https://arxiv.org/abs/1611.03679)

### 13.4.2 MRI reconstruction from undersampled k-space: zero filling, compressed sensing, MoDL and an end-to-end variational network (Lustig, Donoho & Pauly, MRM 2007; Aggarwal, Mani & Jacob, IEEE TMI 2019; Hammernik et al., MRM 2018; Sriram et al., MICCAI 2020)
MRI samples the image's Fourier transform; undersampling speeds acquisition but zero-filled inverse FFTs alias. Compressed-sensing MRI exploits sparsity in a wavelet or TV domain with incoherent random sampling, solved by proximal methods. MoDL alternates a CNN denoiser with a conjugate-gradient data-consistency step, sharing weights across iterations; the variational network (and its end-to-end successor) unrolls gradient steps in which a learned regulariser and soft data consistency are applied in k-space.
- **Block:** `experimental.imaging.MriOperator` (masked 2-D DFT via core `Var.fft2`), `experimental.imaging.CompressedSensingMri` (TV and 13.4.10's wavelet sparsity by FISTA/ADMM) and `experimental.imaging.UnrolledMri` (MODL with CG data consistency, VARNET with k-space soft DC).
- **Experiment:** `experiments.imaging.MriReconstruction`.
- **Toy task:** `InverseProblems` phantoms and `ShapeImages` scenes at 64×64 with 4× and 8× variable-density masks and k-space noise.
- **Baselines:** zero-filled reconstruction; `PlugAndPlay`'s Fourier-domain data step with an `ImageDenoiser` prior (HQS); `UNet2d` on the zero-filled image; wave 12's `UnrolledSolvers` LISTA pattern as a reference unrolling.
- **Expected metric:** PSNR/SSIM at 4× and 8×, and robustness to a different mask at test time. Hypothesis: CS-TV gains 4–6 dB over zero filling; MoDL beats the image-domain U-Net by 2–3 dB at 8× and degrades less under a changed mask because of explicit data consistency; the variational network matches MoDL with fewer CG solves.
- **Source:** [arXiv:1712.02862](https://arxiv.org/abs/1712.02862) (MoDL), [arXiv:2004.06688](https://arxiv.org/abs/2004.06688) (E2E VarNet)

### 13.4.3 Phase retrieval: Gerchberg–Saxton and Fienup HIO, Wirtinger flow and a denoiser-regularised prDeep (Fienup, Appl. Opt. 1982; Candès, Li & Soltanolkotabi, IEEE TIT 2015; Chen & Candès, CPAM 2017; Metzler et al., ICML 2018)
Only Fourier magnitudes |Fx| are measured. Gerchberg–Saxton / error reduction alternates between imposing the measured magnitudes and the object constraints (support, non-negativity); Fienup's hybrid input–output adds a feedback term that escapes stagnation. Wirtinger flow minimises the intensity loss Σ(|aᵢᵀx|² − yᵢ)² by gradient descent from a spectral initialisation, with provable recovery for coded or Gaussian measurements; truncated WF discards outlier gradients. prDeep regularises the problem with a CNN denoiser through regularisation by denoising (RED).
- **Block:** `experimental.imaging.PhaseRetrieval` (ER, HIO, WIRTINGER_FLOW, TRUNCATED_WF, spectral initialisation, PR_DEEP with an `ImageDenoiser` via RED).
- **Experiment:** `experiments.imaging.PhaseRetrieval`.
- **Toy task:** `InverseProblems` 32×32 images with (a) oversampled Fourier magnitudes (classical) and (b) 2–4 coded-diffraction patterns, with Poisson noise.
- **Baselines:** `PlugAndPlay`-style HQS with the `Denoisers` prior on the intensity loss; gradient descent on the intensity loss from a random start (no spectral initialisation).
- **Expected metric:** success rate (relative error < 1e-2 up to global phase and flips) against oversampling or number of patterns, and PSNR under noise. Hypothesis: HIO beats ER on Fourier magnitudes; WF with spectral initialisation succeeds with 3+ coded patterns where random-start gradient descent mostly fails; prDeep gives the best PSNR under strong Poisson noise.
- **Source:** [arXiv:1407.1065](https://arxiv.org/abs/1407.1065) (Wirtinger flow), [arXiv:1803.00212](https://arxiv.org/abs/1803.00212) (prDeep)

### 13.4.4 Blind deconvolution: alternating MAP with ℓ0 gradient priors and coarse-to-fine kernel estimation (Fergus et al., SIGGRAPH 2006; Levin et al., CVPR 2009/2011; Pan et al., CVPR 2014)
When the blur kernel is unknown, naive joint MAP favours the blurry image and a delta kernel. Successful methods estimate the kernel first with a sparsity-promoting prior that favours sharp edges (normalised sparsity, ℓ0 on gradients solved by half-quadratic splitting), alternate kernel and latent-image updates on an image pyramid with kernel non-negativity and normalisation, and finish with a non-blind deconvolution using the estimated kernel.
- **Block:** `experimental.imaging.BlindDeconvolution` (L0_GRADIENT and NORMALISED_SPARSITY priors, kernel update by FFT-domain least squares with projection, coarse-to-fine pyramid; final non-blind step delegated to `PlugAndPlay`).
- **Experiment:** `experiments.imaging.ImageInverseProblems` (blind table).
- **Toy task:** `DegradedImages` / `ShapeImages` at 64×64 blurred by random motion and defocus kernels (7×7 to 15×15) with noise σ ∈ {0.01, 0.02}.
- **Baselines:** `PlugAndPlay.wiener` and HQS with the true kernel (oracle) and with a fixed Gaussian guess; `PlugAndPlay.richardsonLucy` with the guess; a `UNet2d` trained on blurred-to-sharp pairs from the same kernel family (wave 10's direct baseline).
- **Expected metric:** kernel similarity (max normalised cross-correlation), PSNR of the final image, and the error ratio to the oracle (Levin et al.'s metric). Hypothesis: ℓ0 blind deconvolution reaches an error ratio ≤ 3 on 80% of images where the Gaussian guess exceeds 5; the U-Net does well on seen kernel families and worse on unseen large motion kernels, where the blind method keeps its accuracy.
- **Source:** Levin et al., "Efficient marginal likelihood optimization in blind deconvolution" (CVPR 2011); Pan et al., "Deblurring text images via L0-regularized intensity and gradient prior" (CVPR 2014).

### 13.4.5 Demosaicing: bilinear, Malvar–He–Cutler gradient-corrected interpolation, residual interpolation and a learned joint demosaicking network (Malvar, He & Cutler, ICASSP 2004; Kiku et al., ICIP 2013; Gharbi et al., SIGGRAPH Asia 2016)
A Bayer sensor records one colour per pixel. Bilinear interpolation creates zipper and false-colour artefacts at edges. Malvar–He–Cutler adds gradient-correction terms from the other channels with fixed 5×5 filters; residual interpolation interpolates residuals of a guided-filter estimate rather than the colours. Gharbi et al. train a CNN for joint demosaicking and denoising with hard-example mining of moiré-prone patches.
- **Block:** `experimental.imaging.Demosaicing` (BILINEAR, MALVAR, RESIDUAL_INTERPOLATION with 13.4.9's guided filter, LEARNED small CNN with hard-patch mining).
- **Experiment:** `ImageInverseProblems` (demosaicing table).
- **Toy task:** `InverseProblems` Bayer mosaics of 32×32 colour `ShapeImages`/`DegradedImages` scenes with high-frequency stripes (moiré-prone) and noise σ ∈ {0, 0.02}.
- **Baselines:** `SuperResolution` networks (ESPCN/EDSR) adapted to the 4-channel packed mosaic; `UNet2d`; nearest-neighbour fill.
- **Expected metric:** CPSNR and a zipper/false-colour score on edge pixels. Hypothesis: Malvar beats bilinear by 4–6 dB; residual interpolation adds ~1 dB; the learned CNN with hard mining is best on stripes (moiré) and under noise, where it beats a U-Net of the same size trained without mining.
- **Source:** Malvar, He & Cutler, "High-quality linear interpolation for demosaicing of Bayer-patterned color images" (ICASSP 2004); Gharbi et al., "Deep joint demosaicking and denoising" (SIGGRAPH Asia 2016).

### 13.4.6 The deep image prior and its early-stopping problem (Ulyanov, Vedaldi & Lempitsky, CVPR 2018; Wang et al., ICCV 2021)
A randomly initialised convolutional generator fitted to a single degraded image from a fixed noise input reproduces natural structure before noise, so stopping early gives a restoration with no training data. The difficulty is knowing when to stop; ES-WMV monitors the running variance of the reconstructions and stops at its minimum, without ground truth.
- **Block:** `experimental.imaging.DeepImagePrior` (encoder–decoder generator, input noise regularisation, FIXED_ITERATIONS, ORACLE_STOP, ES_WMV; denoising, inpainting and super-resolution forward operators).
- **Experiment:** `ImageInverseProblems` (DIP table).
- **Toy task:** 64×64 `DegradedImages` scenes with Gaussian noise σ = 25/255 and 50% random-pixel inpainting.
- **Baselines:** `Denoisers` (Gaussian, median, NLM); `SelfSupervisedDenoising` (Noise2Self/Neighbor2Neighbor, zero-shot Noise2Noise), the other single-image methods; supervised DnCNN as the ceiling.
- **Expected metric:** PSNR at the oracle stop, at ES-WMV's stop and at a fixed iteration count; iterations to stop. Hypothesis: DIP's oracle PSNR is close to zero-shot Noise2Noise and above NLM; a fixed iteration count loses 2–5 dB by overfitting the noise; ES-WMV recovers most of that gap; on inpainting DIP beats the denoiser-based baselines, which do not model missing pixels.
- **Source:** [arXiv:1711.10925](https://arxiv.org/abs/1711.10925); Wang et al., "Early stopping for deep image prior" (ICCV 2021 / TMLR 2023).

### 13.4.7 Diffusion posterior sampling for linear inverse problems, checked against exact posteriors: DPS, ΠGDM, DDRM and DAPS (Chung et al., ICLR 2023; Song et al., ICLR 2023; Kawar et al., NeurIPS 2022; Zhang et al., CVPR 2025)
Using a pretrained diffusion prior for y = Ax + n, DPS adds the gradient of log p(y | x̂₀(x_t)) through the Tweedie denoiser to every reverse step; ΠGDM uses a pseudo-inverse guidance with a Gaussian approximation of p(x₀ | x_t); DDRM works in the SVD basis of A and denoises the observed and unobserved components differently. DAPS decouples consecutive steps: at each noise level it draws x₀ from an approximate posterior given x_t (Langevin on the measurement likelihood plus a Gaussian prior around the denoiser output) and re-noises to the next level, allowing large corrections that the others cannot make. On a Gaussian-mixture prior the score is analytic and, for linear-Gaussian measurements, the exact posterior is a known mixture, so sample quality can be measured exactly rather than by PSNR alone.
- **Block:** `experimental.imaging.PosteriorSamplers` (DPS, PI_GDM, DDRM, DAPS; any `Score` model; an exact analytic GMM score and a learned score from core `nn.diffusion`).
- **Experiment:** `experiments.imaging.PosteriorSampling` (exact table).
- **Toy task:** `InverseProblems` Gaussian-mixture priors in 2-D (visualisable) and 8-D with 4–16 components; measurements: inpainting (masked coordinates), random projections and a nonlinear |·| measurement (phase-retrieval-like); noise σ_y ∈ {0.05, 0.5}.
- **Baselines:** exact posterior samples (ground truth); `AnnealedImportanceSampler`/SMC and `HamiltonianMonteCarlo` on the exact posterior density (the sampler baselines already in the repo); MAP by gradient ascent.
- **Expected metric:** sliced Wasserstein distance and MMD to exact posterior samples, mode coverage (share of posterior mixture weight recovered), and score evaluations. Hypothesis: DPS is overconfident (collapses onto one mode) at low σ_y; DDRM is exact-ish for linear A but cannot handle the nonlinear measurement; DAPS has the lowest Wasserstein error on the nonlinear case and covers more modes; HMC matches exactness at much higher cost per independent sample.
- **Source:** [arXiv:2209.14687](https://arxiv.org/abs/2209.14687) (DPS), [arXiv:2201.11793](https://arxiv.org/abs/2201.11793) (DDRM), [arXiv:2407.01521](https://arxiv.org/abs/2407.01521) (DAPS)

### 13.4.8 Generative priors for image restoration: diffusion posterior sampling and PnP-Flow with a flow-matching prior (Martin, Gagneux, Hagemann & Steidl, ICLR 2025)
PnP-Flow uses a pretrained flow-matching model as a plug-and-play prior: each iteration takes a gradient step on the data fidelity, interpolates the current estimate back onto the learned flow path at time t (mixing it with fresh noise), and applies the flow's time-dependent denoiser (the predicted endpoint), with t increasing over the iterations. It never backpropagates through the ODE, so it is cheap in memory and time, and the paper reports state-of-the-art results across denoising, deblurring, super-resolution and inpainting against flow and diffusion baselines.
- **Block:** `experimental.imaging.PnpFlow` (built on core `nn.diffusion.FlowMatching` for the prior) and 13.4.7's samplers applied with a small trained image score model.
- **Experiment:** `PosteriorSampling` (image table).
- **Toy task:** 16×16 `ShapeImages` (the size wave 12's learned codec used); flow-matching and diffusion priors trained for a few seconds; tasks: inpainting a 6×6 box, 50% random pixels, Gaussian deblurring, 2× super-resolution.
- **Baselines:** `PlugAndPlay` HQS and ADMM with the FFDNet/DnCNN denoiser trained on the same images; the deep unrolled network (`PlugAndPlay.Unrolled`); 13.4.6's DIP.
- **Expected metric:** PSNR/SSIM and run time per image. Hypothesis: PnP-Flow matches or beats PnP-HQS with a denoiser prior on inpainting (where the generative prior fills structure) and ties on deblurring; DPS with the small diffusion prior is slower and noisier at this training budget; DAPS improves on DPS for the box inpainting.
- **Source:** [arXiv:2410.02423](https://arxiv.org/abs/2410.02423)

### 13.4.9 Primal–dual variational imaging and edge-preserving filters: Chambolle–Pock PDHG for TV/TGV, bilateral, guided and Perona–Malik filtering (Chambolle & Pock, JMIV 2011; Bredies, Kunisch & Pock, SIIMS 2010; Tomasi & Manduchi, ICCV 1998; He, Sun & Tang, ECCV 2010; Perona & Malik, TPAMI 1990)
Total-variation problems are non-smooth; PDHG solves min_x F(Kx) + G(x) through the saddle point with cheap proximal steps and step sizes τσ‖K‖² < 1, handling TV-L2 (Gaussian noise), TV-L1 (impulse noise) and total generalised variation (which avoids staircasing). The bilateral filter averages neighbours weighted by spatial and intensity distance; the guided filter fits a local linear model of the output on a guide image in O(1) per pixel; Perona–Malik anisotropic diffusion smooths within regions but not across edges.
- **Block:** `experimental.imaging.PrimalDual` (PDHG with TV_L2, TV_L1, TGV, and inpainting/deblurring operators) and `experimental.imaging.EdgePreservingFilters` (BILATERAL, GUIDED, PERONA_MALIK).
- **Experiment:** `ImageInverseProblems` (variational table).
- **Toy task:** `DegradedImages` with Gaussian, salt-and-pepper and Poisson–Gaussian noise; piecewise-smooth ramps (where TV staircases).
- **Baselines:** `PlugAndPlay.totalVariation` (TV by plain gradient descent, wave 10), `Denoisers` (Gaussian, median, NLM), DnCNN as the learned reference.
- **Expected metric:** PSNR/SSIM, iterations and time to a fixed objective gap. Hypothesis: PDHG reaches the TV optimum 10–50× faster than the gradient-descent TV baseline; TV-L1 beats TV-L2 and median filtering on salt-and-pepper; TGV beats TV by ≥ 1 dB on ramps; the guided filter is the fastest and NLM the best classical filter on Gaussian noise.
- **Source:** Chambolle & Pock, "A first-order primal-dual algorithm for convex problems with applications to imaging" (JMIV 2011).

### 13.4.10 Wavelet denoising: VisuShrink, SureShrink and BayesShrink with cycle spinning (Donoho & Johnstone, Biometrika 1994 and JASA 1995; Chang, Yu & Vetterli, IEEE TIP 2000; Coifman & Donoho, 1995)
An orthogonal discrete wavelet transform concentrates image structure into few large coefficients; thresholding the detail coefficients denoises. VisuShrink uses the universal threshold σ√(2 log n); SureShrink picks a per-subband threshold minimising Stein's unbiased risk estimate; BayesShrink sets σ²/σ_x per subband from a generalised-Gaussian prior. Cycle spinning averages over shifts to remove the transform's shift-variance artefacts.
- **Block:** `experimental.imaging.Wavelets` (1-D and 2-D DWT with Haar, Daubechies-4 and CDF 9/7 lifting; inverse; VISU_SHRINK, SURE_SHRINK, BAYES_SHRINK; soft/hard; CYCLE_SPINNING; noise estimate by the median absolute deviation of the finest subband).
- **Experiment:** `ImageInverseProblems` (wavelet table).
- **Toy task:** `DegradedImages` with Gaussian noise σ ∈ {10, 25, 50}/255; 1-D Donoho–Johnstone test signals (blocks, bumps, heavisine, doppler).
- **Baselines:** `Denoisers` (Gaussian, NLM); the DCT shrinkage used by wave 12's `DictionaryLearning` overcomplete-DCT baseline; `ScatteringTransform` is not a denoiser and is not used.
- **Expected metric:** PSNR (images) and MSE (1-D signals). Hypothesis: SureShrink and BayesShrink beat VisuShrink by 1–3 dB (VisuShrink oversmooths); cycle spinning adds ~1 dB; NLM still beats wavelet shrinkage on textured images; on the 1-D test signals SureShrink is within a small factor of the oracle-threshold risk.
- **Source:** Donoho & Johnstone, "Adapting to unknown smoothness via wavelet shrinkage" (JASA 1995).

### 13.4.11 Choosing the regularisation parameter: discrepancy principle, L-curve, GCV and Monte-Carlo SURE (Morozov, 1966; Hansen, SIAM Rev. 1992; Golub, Heath & Wahba, Technometrics 1979; Ramani, Blu & Unser, IEEE TIP 2008)
Every regularised reconstruction (Tikhonov, TV, plug-and-play) has a strength λ that is usually tuned against ground truth in experiments. The discrepancy principle picks λ so that the residual matches the noise level; the L-curve picks the corner of the log residual–log norm curve; generalised cross-validation minimises a leave-one-out proxy computable from the influence matrix's trace; Monte-Carlo SURE estimates the MSE of any black-box denoiser or reconstruction with one random probe and a divergence estimate, enabling unsupervised tuning of nonlinear methods.
- **Block:** `experimental.imaging.ParameterChoice` (DISCREPANCY, L_CURVE (maximum curvature), GCV with Hutchinson trace estimates, MC_SURE), applicable to any `λ → reconstruction` function.
- **Experiment:** `ImageInverseProblems` (parameter table).
- **Toy task:** Tikhonov deblurring, TV denoising (13.4.9), wavelet thresholds (13.4.10) and PnP-HQS's λ on `DegradedImages`; known and misestimated noise levels.
- **Baselines:** the oracle λ (best PSNR on ground truth); a fixed default λ; `KernelGaussianProcess`-style marginal-likelihood tuning for the Tikhonov case.
- **Expected metric:** PSNR loss relative to the oracle λ and the ratio λ̂/λ_oracle. Hypothesis: MC-SURE is within 0.2 dB of the oracle for every method, including the nonlinear PnP; GCV matches it for linear Tikhonov; the discrepancy principle oversmooths when σ is overestimated by 20%; the L-curve is the least reliable.
- **Source:** Ramani, Blu & Unser, "Monte-Carlo SURE: a black-box optimization of regularization parameters for general denoising algorithms" (IEEE TIP 2008).

### 13.4.12 Single-pixel imaging with Hadamard, random and learned patterns (Duarte et al., IEEE SPM 2008; Higham et al., Sci. Rep. 2018)
A single-pixel camera measures inner products of the scene with a sequence of patterns. Ordered Hadamard patterns with low-frequency ordering give a fast exact inverse at full sampling and graceful truncation; random ±1 patterns allow compressed-sensing recovery at low sampling ratios; learning the pattern matrix jointly with a decoder (a deep compressed-sensing autoencoder) adapts both to the image class and improves quality at a few percent sampling.
- **Block:** `experimental.imaging.SinglePixelImaging` (fast Walsh–Hadamard transform with sequency and "cake-cutting" orderings; RANDOM patterns with CS recovery delegated to wave 12's `SparseRecovery` FISTA/TV; LEARNED binarised patterns with a small decoder, straight-through).
- **Experiment:** `ImageInverseProblems` (single-pixel table).
- **Toy task:** 32×32 `ShapeImages` at sampling ratios 2–25% with detector noise.
- **Baselines:** wave 12's `SparseRecovery` (OMP/FISTA/AMP with random Gaussian sensing) and `UnrolledSolvers` (LISTA) as the CS references; truncated DCT sampling as a fixed-transform reference.
- **Expected metric:** PSNR/SSIM against sampling ratio. Hypothesis: low-frequency Hadamard beats random patterns with CS at ≥ 10% sampling; CS with random patterns wins only in the sparse-image regime; learned patterns with the decoder are best at 2–5% by 2–4 dB.
- **Source:** Duarte et al., "Single-pixel imaging via compressive sampling" (IEEE Signal Processing Magazine 2008); Higham et al., "Deep learning for real-time single-pixel video" (Sci. Rep. 2018).

### 13.4.13 Adaptive filters: LMS, NLMS, affine projection, RLS and a Kalman-filter adaptive filter, for system identification and echo cancellation (Widrow & Hoff, 1960; Haykin, Adaptive Filter Theory; Ozeki & Umeda, 1984; Enzner & Vary, Signal Processing 2006)
An adaptive FIR filter tracks an unknown, possibly time-varying system online. LMS takes a stochastic-gradient step per sample; NLMS normalises by input power; affine projection reuses the last K inputs to speed convergence for coloured inputs; RLS minimises exponentially weighted least squares with O(N²) updates and converges in ~2N samples. Acoustic echo cancellation subtracts the estimated echo of the far-end signal from the microphone signal, and needs double-talk robustness (a Kalman state-space formulation in the frequency domain gives one).
- **Block:** `experimental.sensing.AdaptiveFilters` (LMS, NLMS, APA, RLS, KALMAN_FIR; double-talk detection by the Geigel test).
- **Experiment:** `experiments.sensing.AdaptiveFilters`.
- **Toy task:** `ArraySignals` system identification with white and AR(1)-coloured input, abrupt and slowly drifting systems; echo cancellation with synthetic room impulse responses, speech-like coloured far-end signals and double-talk.
- **Baselines:** offline least squares on the whole record (core `LeastSquares.ols`, the batch optimum); `FtrlProximal`-style online gradient descent as a generic online learner.
- **Expected metric:** misalignment ‖ŵ − w‖²/‖w‖² over time, steady-state error, tracking after a change, and echo-return-loss enhancement (ERLE). Hypothesis: RLS converges ~10× faster than NLMS on coloured input; APA (K = 4) sits between them at much lower cost than RLS; LMS diverges without careful step sizes on non-stationary input; the Kalman filter keeps ERLE during double-talk where NLMS without detection diverges.
- **Source:** Haykin, Adaptive Filter Theory (5th ed.); Enzner & Vary, "Frequency-domain adaptive Kalman filter for acoustic echo control in hands-free telephones" (Signal Processing 2006).

### 13.4.14 Beamforming and direction finding: delay-and-sum, MVDR/Capon, MUSIC, root-MUSIC and ESPRIT with spatial smoothing (Capon, Proc. IEEE 1969; Schmidt, IEEE TAP 1986; Barabell, ICASSP 1983; Roy & Kailath, IEEE TASSP 1989; Shan, Wax & Kailath, 1985)
Sensor arrays estimate the directions of arrival (DOA) of narrowband sources from the sample covariance of snapshots. Delay-and-sum beamforming scans the steering vector and is limited by the array's beamwidth; Capon's MVDR minimises output power subject to unit gain in the look direction and resolves closer sources. Subspace methods use the eigendecomposition: MUSIC scans the noise subspace's orthogonality, root-MUSIC solves for the roots of a polynomial, and ESPRIT exploits the shift invariance between two subarrays in closed form. Coherent sources collapse the signal subspace; forward–backward spatial smoothing restores it.
- **Block:** `experimental.sensing.ArrayProcessing` (ULA steering vectors, sample covariance, DELAY_AND_SUM, MVDR, MUSIC, ROOT_MUSIC, ESPRIT, spatial smoothing, MDL/AIC source-number estimation, the Cramér–Rao bound), with eigendecompositions from core `tensor.Matrices` (complex as real 2M × 2M where needed).
- **Experiment:** `experiments.sensing.DirectionFinding`.
- **Toy task:** `ArraySignals` ULA with M = 8–16, K = 2–4 sources, separations 2–20°, SNR −10 to 20 dB, 10–200 snapshots, coherent sources and gain/phase miscalibration.
- **Baselines:** the spatial periodogram (core `Fft` over the array); a direct MLP regressing angles from the covariance (the "learn everything" baseline); the CRB as the bound.
- **Expected metric:** RMSE in degrees against SNR and snapshots, resolution probability of close sources, and source-count accuracy. Hypothesis: MUSIC and ESPRIT approach the CRB above 0 dB with ≥ 50 snapshots and resolve sources 3× closer than delay-and-sum; with coherent sources plain MUSIC fails and spatial smoothing recovers it at the cost of aperture; the direct MLP is competitive only inside its training conditions.
- **Source:** Schmidt, "Multiple emitter location and signal parameter estimation" (IEEE TAP 1986); Roy & Kailath, "ESPRIT" (IEEE TASSP 1989).

### 13.4.15 SubspaceNet: deep-learning-aided subspace methods with a learned covariance, trained through differentiable MUSIC/root-MUSIC, and near-field DCD-MUSIC (Shmuel et al., 2023/2024; Gast, Le Magoarou & Shlezinger, Apr 2025)
Subspace methods break with coherent sources, few snapshots or miscalibration because the sample covariance is poor. SubspaceNet keeps MUSIC/root-MUSIC as the final estimator but replaces the covariance with a learned surrogate computed by a small network from the snapshots' autocorrelations, trained end-to-end through the differentiable subspace method with an angle loss (no ground-truth covariance needed). The 2025 near-field extension estimates angles with a far-field ESPRIT-style step and then each source's range by 1-D MUSIC (DCD-MUSIC), and adds a model-order-aware loss. Here the eigendecomposition gradient comes from the new core `autograd.Decompositions.eigh`.
- **Block:** `experimental.sensing.SubspaceNet` (autocorrelation features, learned Hermitian PSD surrogate, differentiable MUSIC spectrum loss and root-MUSIC via `Decompositions.eigh`; NEAR_FIELD DCD variant).
- **Experiment:** `DirectionFinding` (learned table).
- **Toy task:** `ArraySignals` with coherent sources, 10–20 snapshots, miscalibrated arrays, and a near-field configuration (sources within the Fraunhofer distance).
- **Baselines:** 13.4.14's MUSIC, root-MUSIC, ESPRIT with spatial smoothing; the direct-regression MLP of 13.4.14; the CRB.
- **Expected metric:** RMSE (angle, and range for near field) and resolution probability. Hypothesis: SubspaceNet beats spatially smoothed MUSIC with coherent sources and 10 snapshots by ≥ 2× in RMSE and degrades gracefully under miscalibration; in the near field, DCD-MUSIC with a learned covariance resolves sources that 2-D MUSIC on the sample covariance misses; the direct MLP is worse outside its training SNR range.
- **Source:** [arXiv:2306.02271](https://arxiv.org/abs/2306.02271), [arXiv:2504.00599](https://arxiv.org/abs/2504.00599)

### 13.4.16 Classical spectral estimation: Welch, multitaper, Burg autoregressive spectra and the Lomb–Scargle periodogram (Welch, 1967; Thomson, Proc. IEEE 1982; Burg, 1967; Lomb, 1976; Scargle, ApJ 1982)
The raw periodogram is inconsistent. Welch's method averages windowed, overlapping segment periodograms (trading resolution for variance); Thomson's multitaper method averages periodograms with orthogonal Slepian (DPSS) tapers for near-optimal bias–variance and has an F-test for line components; Burg's method fits an AR model by minimising forward and backward prediction errors, giving sharp peaks from short records. For irregularly sampled data the Lomb–Scargle periodogram fits sinusoids by least squares at each frequency, with a false-alarm probability.
- **Block:** `experimental.sensing.SpectralEstimation` (PERIODOGRAM, WELCH, MULTITAPER with DPSS from the tridiagonal eigenproblem via core `Matrices`, BURG with order selection by AIC, LOMB_SCARGLE with false-alarm probability; harmonic F-test).
- **Experiment:** `experiments.sensing.SpectralEstimation`.
- **Toy task:** `ArraySignals` sums of 1–3 sinusoids in AR(2) coloured noise (short and long records, closely spaced lines) and irregularly sampled versions with gaps (`IrregularSeries`-style timestamps).
- **Baselines:** the raw periodogram (core `Fft`); `Arima` fitted spectra; `IrregularSequenceModels` are not spectral estimators, so the irregular case is compared against interpolate-then-FFT.
- **Expected metric:** frequency RMSE, resolution of two close lines, log-spectral distance to the true PSD, and detection ROC for a weak line. Hypothesis: multitaper has the lowest log-spectral distance; Burg resolves two lines from 64 samples where Welch cannot; Lomb–Scargle detects the weak line on irregular data where interpolate-then-FFT produces spurious peaks.
- **Source:** Thomson, "Spectrum estimation and harmonic analysis" (Proc. IEEE 1982); Scargle, "Studies in astronomical time series analysis II" (ApJ 1982).

### 13.4.17 Deep Closest Point with a differentiable SVD — follow-up (Wang & Solomon, ICCV 2019)
Wave 12's 12.3.8 implemented DCP without a differentiable SVD (none was in core), solving the Procrustes step with a Horn quaternion power iteration, and found DCP weak (success 0.00 at 15° alone, 0.63 with ICP at 90°). DCP's soft correspondences from attention over learned point features feed a weighted Kabsch/Procrustes step whose rotation comes from the SVD of the cross-covariance; with the new core `autograd.Decompositions.svd`, gradients flow through the exact SVD. The follow-up measures whether exact SVD gradients (with the sign correction for reflections) change DCP's result at the same training budget.
- **Block:** a `DeepClosestPoint` option `Procrustes.SVD` in `experimental.geometry` (default stays the wave 12 power iteration, so wave 12 numbers do not move).
- **Experiment:** a new `MultiViewGeometry.registrationSvd` method in `experiments.robotics` (existing rows unchanged).
- **Toy task:** wave 12's `GeometryScenes` registration task at 15°, 45° and 90° with the same budgets.
- **Baselines:** wave 12's DCP with the quaternion power iteration, ICP point-to-point and point-to-plane, DCP + ICP, `PointNet` regression (all read-only).
- **Expected metric:** success rate and median rotation error. Hypothesis: the SVD version trains more stably and lifts DCP-alone success at 15°–45° clearly above 0 and DCP + ICP at 90° above 0.63; if not, the wave 12 weakness was the training budget, not the Procrustes solver, which is itself a useful negative result.
- **Source:** [arXiv:1905.03304](https://arxiv.org/abs/1905.03304)

### 13.5.1 Neural likelihood estimation with MCMC (Papamakarios, Sterratt & Murray, AISTATS 2019; Lueckmann et al., AISTATS 2021)
Neural posterior estimation (in the repo since wave 8) learns q(θ | x) directly and is amortised but must model the posterior's whole shape. Neural likelihood estimation instead learns a conditional density q(x | θ) of the data given parameters, then samples p(θ | x_o) ∝ q(x_o | θ)p(θ) by MCMC; it can reuse the learned likelihood for several observations i.i.d. by summing log-likelihoods, which NPE cannot do without retraining. Sequential NLE (SNL) retrains on simulations from the current posterior.
- **Block:** `experimental.sbi.NeuralLikelihood` (MDN and affine-coupling flow conditional densities, MCMC by slice sampling or `HamiltonianMonteCarlo` on the learned likelihood; SEQUENTIAL rounds).
- **Experiment:** `experiments.inference.LikelihoodFree` and new rows in `SimulatorInference`.
- **Toy task:** Gaussian linear and two moons (existing), SLCP and Bernoulli GLM from `SimulatorSuite`, and i.i.d. data sets of 1–20 observations.
- **Baselines:** `SimulationBasedInference.neuralPosterior` (MDN NPE), `smcAbc` and `rejectionAbc`, at equal simulation budgets; reference posteriors.
- **Expected metric:** C2ST against reference posteriors (`SimulationBasedInference.c2st`, 0.5 is perfect) at 10³ and 10⁴ simulations, and accuracy as the number of i.i.d. observations grows. Hypothesis: NLE beats NPE on SLCP (a simple likelihood with a complex posterior) and when trials are i.i.d.; NPE wins on two moons at low budgets; both beat SMC-ABC at equal simulations.
- **Source:** [arXiv:1805.07226](https://arxiv.org/abs/1805.07226)

### 13.5.2 Neural ratio estimation: NRE-A, contrastive NRE and balanced NRE (Hermans, Begy & Louppe, ICML 2020; Miller, Weniger & Forré, NeurIPS 2022; Delaunoy et al., NeurIPS 2022)
A classifier trained to tell joint pairs (θ, x) from marginal pairs (θ', x) learns the likelihood-to-evidence ratio r(θ, x) = p(x|θ)/p(x); multiplying by the prior gives the posterior, sampled by MCMC or importance resampling. Contrastive NRE trains a multiclass classifier among K candidate parameters, which improves the ratio's accuracy; balanced NRE adds a balancing regulariser that makes the classifier conservative, reducing the overconfident posteriors that amortised SBI often produces.
- **Block:** `experimental.sbi.NeuralRatio` (NRE_A, NRE_C with K contrastive classes, BNRE with balancing weight λ; sampling by MCMC on log r + log prior).
- **Experiment:** `LikelihoodFree` (ratio table).
- **Toy task:** the 13.5.1 simulators.
- **Baselines:** MDN NPE; 13.5.1's NLE; SMC-ABC.
- **Expected metric:** C2ST and expected coverage (13.5.6) at 10³ and 10⁴ simulations. Hypothesis: NRE-C improves C2ST over NRE-A at equal budgets; BNRE's expected-coverage curve lies on or above the diagonal (conservative) where NRE-A and NPE are overconfident at 10³ simulations, at a small cost in C2ST.
- **Source:** [arXiv:1903.04057](https://arxiv.org/abs/1903.04057) (NRE); [arXiv:2208.13624](https://arxiv.org/abs/2208.13624) (BNRE)

### 13.5.3 Flow-matching and score-based posterior estimation: FMPE and NPSE (Dax et al., NeurIPS 2023; Sharrock et al., ICML 2024; Geffner, Papamakarios & Mnih, ICML 2023)
Mixture density networks and discrete flows limit NPE's expressiveness. Flow-matching posterior estimation trains a conditional vector field v(θ_t, t, x) by regressing on straight-line interpolations between noise and prior samples, and samples the posterior by integrating the ODE; it trains faster than discrete flows and scales to complex posteriors. Score-based NPE trains a conditional diffusion score and can also combine scores of several i.i.d. observations by composition.
- **Block:** `experimental.sbi.FlowMatchingPosterior` (FMPE via core `nn.diffusion.FlowMatching` conditioned on x embeddings; NPSE with a conditional score and composition for i.i.d. data).
- **Experiment:** `LikelihoodFree` (flow table).
- **Toy task:** two moons (crescent posterior), SLCP (four-mode posterior) and the Gaussian mixture from `SimulatorSuite`.
- **Baselines:** MDN NPE; a discrete-flow NPE using `experimental.nn.DensityFlow` as the conditional density (if its conditioning interface suffices; otherwise an affine-coupling flow in the block); 13.5.1's NLE.
- **Expected metric:** C2ST against budget and training time. Hypothesis: FMPE reaches the best C2ST on SLCP and two moons at 10⁴ simulations, with the MDN missing modes; at 10³ simulations FMPE and the MDN are close; NPSE composition beats NPE trained on single observations for 10 i.i.d. trials.
- **Source:** [arXiv:2305.17161](https://arxiv.org/abs/2305.17161) (FMPE); Sharrock et al., "Sequential neural score estimation" (ICML 2024).

### 13.5.4 Sequential NPE: APT/SNPE-C with the atomic loss, and truncated sequential NPE (Greenberg, Nonnenmacher & Macke, ICML 2019; Deistler, Goncalves & Macke, NeurIPS 2022)
When only one observation matters, simulating from the prior wastes budget. Sequential NPE proposes new simulations from the current posterior estimate; because training data are no longer prior samples, the loss must be corrected: APT's atomic loss normalises the posterior over a small set of contrasting parameters, avoiding importance weights. TSNPE instead samples from the prior truncated to the current highest-probability region, keeping maximum-likelihood training valid, and is more robust.
- **Block:** `experimental.sbi.SequentialPosterior` (APT_ATOMIC, TSNPE with a highest-density-region truncation by the current posterior's density quantile; rounds and per-round budgets).
- **Experiment:** `LikelihoodFree` (sequential table) and rows in `SimulatorInference.lotkaVolterra`.
- **Toy task:** Lotka–Volterra (existing), SLCP, and the SIR simulator from `SimulatorSuite`.
- **Baselines:** amortised MDN NPE at the same total budget; `smcAbc` (itself sequential); 13.5.1's SNL.
- **Expected metric:** C2ST or posterior-mean RMSE against total simulations (10³–10⁴), and failure rate (diverging rounds) over 5 seeds. Hypothesis: both sequential methods reach amortised NPE's accuracy at 3–10× fewer simulations; APT is occasionally unstable (leakage of mass outside the prior), TSNPE does not fail in any seed.
- **Source:** [arXiv:1905.07488](https://arxiv.org/abs/1905.07488) (APT), [arXiv:2210.04815](https://arxiv.org/abs/2210.04815) (TSNPE)

### 13.5.5 Summary statistics for ABC: regression adjustment, semi-automatic ABC and learned summary networks (Beaumont, Zhang & Balding, Genetics 2002; Fearnhead & Prangle, JRSS-B 2012; Chen et al., ICLR 2021)
Rejection ABC depends on the summaries s(x) and the tolerance. Regression adjustment corrects accepted parameters by a local-linear regression of θ on s(x) − s(x_o), allowing a larger tolerance. Semi-automatic ABC uses the regression's fitted values E[θ | x] (from a pilot run) as summaries, which are optimal for posterior-mean estimation. Learned summary networks generalise this: train a network to predict θ (or maximise mutual information between s(x) and θ, as in Chen et al.'s infomax summaries) and use it inside ABC or NPE.
- **Block:** `experimental.sbi.SummaryStatistics` (REGRESSION_ADJUSTMENT local-linear with Epanechnikov weights, SEMI_AUTOMATIC with linear or MLP regression, INFOMAX summary network via wave 12's `estimators.MutualInformation` InfoNCE bound).
- **Experiment:** `LikelihoodFree` (summary table).
- **Toy task:** the Ricker-like population model and Lotka–Volterra with raw time series (no hand summaries), and the Bernoulli GLM with raw vs summarised data from `SimulatorSuite`.
- **Baselines:** `SimulationBasedInference.rejectionAbc` and `smcAbc` with the existing hand-crafted summaries; NPE on raw data with an MLP embedding.
- **Expected metric:** posterior-mean RMSE and posterior-SD calibration at equal simulations. Hypothesis: regression adjustment halves rejection ABC's error at the same tolerance; semi-automatic summaries beat hand summaries on the Ricker model; ABC with learned summaries approaches NPE, and NPE with a learned embedding remains best.
- **Source:** Beaumont, Zhang & Balding, "Approximate Bayesian computation in population genetics" (Genetics 2002); Fearnhead & Prangle (JRSS-B 2012).

### 13.5.6 Posterior diagnostics: simulation-based calibration, TARP coverage and local C2ST (Talts et al., 2018; Lemos et al., ICML 2023; Linhart et al., NeurIPS 2023)
Comparing to a reference posterior is impossible on real problems. Simulation-based calibration draws θ ~ prior, x ~ simulator, posterior samples given x, and checks that the rank of θ among the samples is uniform (with χ² or KS tests on histograms); ∪-shaped histograms mean overconfidence. TARP checks expected coverage of random-reference-point balls and is necessary and sufficient for accuracy. L-C2ST trains a classifier on joint samples to give a local, per-observation test of whether q(θ | x_o) matches the true posterior, without reference samples.
- **Block:** `experimental.sbi.PosteriorDiagnostics` (SBC ranks and uniformity tests with core `Distributions` χ², EXPECTED_COVERAGE, TARP, L_C2ST with the k-NN or MLP classifier from `estimators.ClassifierTwoSample`).
- **Experiment:** `experiments.inference.PosteriorDiagnostics`.
- **Toy task:** posteriors from 13.5.1–13.5.4 and NPE on Gaussian linear and two moons, deliberately degraded (temperature-scaled over- and under-dispersed, shifted, mode-dropping) as known failures.
- **Baselines:** `SimulationBasedInference.c2st` against reference samples (the oracle diagnostic); posterior predictive checks by eye-free statistics.
- **Expected metric:** detection rate of each planted failure at a fixed false-alarm rate over 100–300 SBC draws, and agreement with the oracle C2ST. Hypothesis: SBC and expected coverage catch dispersion errors but miss some symmetric shifts that TARP catches; L-C2ST flags the failing observations locally and correlates with the oracle C2ST (rank correlation ≥ 0.7); mode dropping is missed by SBC on 1-D marginals and caught by TARP.
- **Source:** [arXiv:1804.06788](https://arxiv.org/abs/1804.06788) (SBC), [arXiv:2302.03026](https://arxiv.org/abs/2302.03026) (TARP), [arXiv:2306.03580](https://arxiv.org/abs/2306.03580) (L-C2ST)

### 13.5.7 SBI under model misspecification: RoPE with optimal transport, robust variational NPE and error-model RNPE (Wehenkel et al., ICML 2025; O'Callaghan, Mandel & Gilmore, Sep 2025; Ward et al., NeurIPS 2022)
Amortised posteriors become confidently wrong when real data differ from simulations. RoPE trains NPE with a learned summary on simulations, then uses a small real calibration set with known parameters: the gap between real and simulated summaries is modelled as an optimal-transport coupling (entropic OT), and the posterior for a real observation mixes NPE posteriors of the simulated summaries it is coupled to, trading calibration against informativeness. RVNP learns an explicit error model jointly with a variational posterior so that the misspecification strength is learned from data rather than set by hand. RNPE adds a spike-and-slab error model on summaries and denoises them by MCMC before applying NPE.
- **Block:** `experimental.sbi.MisspecificationRobust` (ROPE with core `autograd.OptimalTransport.sinkhorn` (newly available differentiable Sinkhorn), RVNP-style learned additive error model, RNPE spike-and-slab denoising; misspecification detection by MMD between real and simulated summaries via `KernelTests`).
- **Experiment:** `experiments.inference.Misspecification`.
- **Toy task:** `SimulatorSuite` misspecified variants: Gaussian linear with heavy-tailed real noise, SIR with an unmodelled reporting delay, a Ricker model with an extra process; calibration sets of 10–100 real (θ, x) pairs.
- **Baselines:** MDN NPE trained on simulations only; NPE fine-tuned on the calibration set (the naive use of the real pairs); 13.5.2's BNRE (conservative, but not misspecification-aware).
- **Expected metric:** coverage of true parameters at 90% credible level, posterior log density of the true θ, and C2ST to the posterior under the true model. Hypothesis: plain NPE's coverage drops to 0.2–0.5 under misspecification; RoPE restores coverage to ≈ 0.9 with 50 calibration pairs and remains more informative than BNRE; fine-tuning on so few pairs overfits; RVNP and RNPE restore coverage without calibration pairs but are less informative.
- **Source:** [ICML 2025 poster (RoPE)](https://icml.cc/virtual/2025/poster/43556); [arXiv:2509.05724](https://arxiv.org/abs/2509.05724) (RVNP)

### 13.5.8 Bayesian experimental design: nested Monte Carlo EIG and variational bounds (Lindley, 1956; Foster et al., NeurIPS 2019; Kleinegesse & Gutmann, ICML 2020)
Bayesian optimal experimental design picks the design ξ maximising the expected information gain EIG(ξ) = E[log p(y|θ,ξ) − log p(y|ξ)]. Nested Monte Carlo is consistent but biased with an O(N·M) cost. Foster et al. give variational estimators — the posterior bound, the marginal bound, and the prior contrastive estimation (PCE) lower and nested-contrastive upper bounds — that are cheaper and differentiable in ξ, so designs can be optimised by stochastic gradients. For implicit models, mutual-information neural estimators (MINEBED) give the bound.
- **Block:** `experimental.design.InformationGain` (NMC, PCE lower bound, NCE upper bound, POSTERIOR and MARGINAL variational bounds, MINE-style bound reusing wave 12's `estimators.MutualInformation`), `experimental.design.DesignOptimiser` (grid, `Optimize.cmaEs`, gradient ascent on PCE).
- **Experiment:** `experiments.inference.ExperimentalDesign` (static table).
- **Toy task:** `SimulatorSuite` location finding (K = 1–2 sources, 2-D designs), the death process (observation time), a linear-Gaussian design with closed-form EIG for validation, and CES preference elicitation.
- **Baselines:** random designs; space-filling grids; `GaussianProcess` + expected-improvement Bayesian optimisation on noisy NMC estimates (`ModelBasedSearch`); the closed-form EIG.
- **Expected metric:** estimator bias and variance against the closed form at equal cost; EIG of the selected design; posterior entropy after the experiment. Hypothesis: PCE and NCE bracket the true EIG and converge as contrastive samples grow, with far lower variance than NMC at equal cost; gradient ascent on PCE finds designs within 2% of the optimal EIG on location finding, beating random designs by ≥ 30%.
- **Source:** [arXiv:1903.05480](https://arxiv.org/abs/1903.05480)

### 13.5.9 Deep adaptive design and semi-amortised Step-DAD (Foster et al., ICML 2021; Hedman, Ivanova, Guan & Rainforth, ICML 2025)
Sequential (adaptive) design re-optimises after each observation, which is expensive at experiment time. DAD trains a design policy network offline, mapping the history of designs and outcomes to the next design, by maximising a sequential PCE bound on total information gain; at deployment it is a single forward pass per step. Step-DAD keeps DAD's up-front training but periodically refines the policy during the experiment on posterior samples given the data so far, adapting to the specific instance and improving robustness, especially when the true parameters lie in a low-prior region.
- **Block:** `experimental.design.AdaptiveDesign` (DAD policy with permutation-invariant history encoder, sequential PCE training; STEP_DAD refinement at chosen steps with posterior samples from importance sampling or 13.5.1's NLE; MYOPIC re-optimisation as the classical baseline).
- **Experiment:** `ExperimentalDesign` (adaptive table).
- **Toy task:** location finding with T = 10–30 sequential measurements and the death process with T = 4; prior-shifted test instances for robustness.
- **Baselines:** random and static designs from 13.5.8; myopic greedy re-optimisation of one-step EIG (the expensive classical approach); `ActiveLearner`-style uncertainty sampling.
- **Expected metric:** total EIG (sPCE bound) at T, final posterior error of the source locations, and decision-time cost per step. Hypothesis: DAD matches myopic re-optimisation in total EIG at ~1000× less decision time; Step-DAD improves on DAD by a few nats, and by more on prior-shifted instances; random designs are far behind.
- **Source:** [arXiv:2103.02438](https://arxiv.org/abs/2103.02438) (DAD), [arXiv:2507.14057](https://arxiv.org/abs/2507.14057) (Step-DAD)

### 13.5.10 Quasi-Monte Carlo: Halton, scrambled Sobol and rank-1 lattices, with randomised QMC error bars and QMC for variational inference (Owen, 1997; Dick, Kuo & Sloan, Acta Numerica 2013; Buchholz, Wenzel & Mandt, ICML 2018)
Monte Carlo integration converges at O(n^{−1/2}); low-discrepancy sequences fill space evenly and achieve close to O(n^{−1}) for smooth integrands of moderate effective dimension. Halton sequences use coprime-base radical inverses; Sobol sequences use direction numbers with Owen scrambling (randomisation that keeps the low discrepancy and gives unbiased estimates with error bars from independent replicates); rank-1 lattice rules with random shifts are optimal for periodic integrands. Replacing the Gaussian samples of reparameterisation gradients by RQMC points lowers their variance and speeds up VI.
- **Block:** `experimental.quadrature.LowDiscrepancy` (HALTON with scrambling, SOBOL with Joe–Kuo direction numbers and Owen/linear-matrix scrambling, LATTICE with random shift; inverse-CDF mapping to Gaussians via core `Distributions`) and `experimental.quadrature.RqmcEstimator`.
- **Experiment:** `experiments.inference.Integration` (QMC table).
- **Toy task:** Genz test integrands in d = 2–32, Gaussian expectations (option-price-like payoffs from wave 12's `MarketPaths`), and the reparameterised ELBO gradients of `FlowVariationalInference`/ADVI on the `LogDensity` banana and funnel.
- **Baselines:** plain Monte Carlo; `CollocationSampler`'s Latin hypercube (the only stratified sampler in the repo); antithetic sampling.
- **Expected metric:** RMSE against n (slope on log–log), and ELBO-gradient variance and steps to converge in VI. Hypothesis: scrambled Sobol reaches slopes near −1 on smooth low-effective-dimension integrands and ≈ −0.5 on discontinuous ones; Latin hypercube helps only for additive integrands; RQMC cuts VI gradient variance by ≥ 5× and reaches the same ELBO in fewer steps.
- **Source:** Dick, Kuo & Sloan, "High-dimensional integration: the quasi-Monte Carlo way" (Acta Numerica 2013); Buchholz, Wenzel & Mandt, "Quasi-Monte Carlo variational inference" (ICML 2018).

### 13.5.11 Bayesian quadrature, kernel herding and Gaussian cubature (O'Hagan, JSPI 1991; Rasmussen & Ghahramani, NeurIPS 2003; Chen, Welling & Smola, UAI 2010; Huszár & Duvenaud, UAI 2012; Gerstner & Griebel, 1998)
Bayesian quadrature places a GP prior on the integrand and integrates the posterior mean analytically against the measure (closed form for Gaussian kernels and Gaussian measures), giving an estimate with uncertainty and optimal weights for any point set. Choosing points to minimise the posterior variance of the integral gives sequential BQ; kernel herding greedily picks points so their empirical kernel mean matches the target's, achieving O(1/n) for the MMD; Huszár and Duvenaud showed herding is BQ with uniform weights. Gauss–Hermite product rules and Smolyak sparse grids are the deterministic cubature references.
- **Block:** `experimental.quadrature.BayesianQuadrature` (Gaussian kernel–Gaussian measure closed forms, sequential variance-minimising design, WSABI-style warped BQ for positive integrands), `experimental.quadrature.KernelHerding` and `experimental.quadrature.Cubature` (GAUSS_HERMITE via Golub–Welsch on core `Matrices`, SMOLYAK sparse grids).
- **Experiment:** `Integration` (BQ table).
- **Toy task:** expensive-integrand toys: Gaussian-measure integrals in d = 1–8 of smooth and rough functions, and model evidences (marginal likelihoods) of small Bayesian regressions where the integrand is the likelihood.
- **Baselines:** 13.5.10's MC and scrambled Sobol at equal evaluations; `NestedSampling` and `AnnealedImportanceSampler` for the evidence case; `GaussianProcess` itself for the GP fit.
- **Expected metric:** absolute error and calibration of BQ's credible interval against evaluations (10–200). Hypothesis: BQ beats MC and QMC by orders of magnitude on smooth integrands with ≤ 50 evaluations in d ≤ 4 and its intervals are calibrated; it loses its edge for d ≥ 8 or rough integrands; herding's MMD falls as O(1/n) against O(n^{−1/2}) for i.i.d. samples; sparse grids beat product Gauss–Hermite from d ≥ 4.
- **Source:** Rasmussen & Ghahramani, "Bayesian Monte Carlo" (NeurIPS 2003); Chen, Welling & Smola, "Super-samples from kernel herding" (UAI 2010).

### 13.5.12 Model checking and averaging: PSIS-LOO, WAIC and Bayesian stacking (Vehtari, Gelman & Gabry, Stat. Comput. 2017; Vehtari et al., JMLR 2024; Watanabe, JMLR 2010; Yao et al., Bayesian Analysis 2018)
Leave-one-out cross-validation measures predictive accuracy but refitting n times is expensive. Importance sampling with weights 1/p(yᵢ | θ) from the full posterior approximates LOO, but the weights are heavy-tailed; Pareto-smoothed importance sampling fits a generalised Pareto to the largest weights and replaces them by expected order statistics, and the fitted shape k̂ diagnoses reliability (k̂ > 0.7 means refit). WAIC is the asymptotic alternative. Bayesian stacking chooses model weights maximising the LOO log score of the mixture, which beats Bayesian model averaging when the true model is not in the candidate set.
- **Block:** `experimental.stats.ModelComparison` (PSIS with k̂ diagnostics, PSIS_LOO, WAIC, exact K-fold for comparison, STACKING weights by convex optimisation, pseudo-BMA+); its GPD fit is shared with 13.5.13.
- **Experiment:** `experiments.inference.ModelChecking`.
- **Toy task:** Bayesian linear and logistic regressions and a hierarchical model sampled with `HamiltonianMonteCarlo`, with planted outliers (high k̂) and an M-open setting where no candidate is the truth (mixture of a linear and a quadratic truth).
- **Baselines:** exact LOO by refitting (ground truth); BMA weights from evidences (`AnnealedImportanceSampler`/`NestedSampling`); picking the single best model by LOO.
- **Expected metric:** absolute error of elpd_loo against exact LOO, k̂'s detection of problematic points, and held-out log score of stacked vs BMA vs single-best predictions. Hypothesis: PSIS-LOO matches exact LOO within 0.5 elpd where plain IS-LOO is unstable; k̂ > 0.7 flags the planted outliers; in the M-open case stacking beats BMA (which puts nearly all weight on one model) on held-out log score.
- **Source:** [arXiv:1507.04544](https://arxiv.org/abs/1507.04544) (PSIS-LOO), [arXiv:1704.02030](https://arxiv.org/abs/1704.02030) (stacking)

### 13.5.13 Extreme value theory: peaks over threshold with the generalised Pareto, Hill estimators, GEV block maxima and SPOT anomaly thresholds (Pickands, Annals 1975; Hill, Annals 1975; Coles, 2001; Siffer et al., KDD 2017)
Extreme quantiles (VaR at 99.9%, flood levels, anomaly thresholds at 10⁻⁴ false-alarm rates) are beyond the range of the empirical distribution. The Pickands–Balkema–de Haan theorem says exceedances over a high threshold are approximately generalised Pareto, whose MLE (or probability-weighted moments) gives extrapolated quantiles; the Hill estimator gives the tail index of heavy tails; GEV fits block maxima. SPOT applies POT to streaming anomaly scores, giving a threshold for a target false-alarm probability that updates online; DSPOT handles drift.
- **Block:** `experimental.stats.ExtremeValues` (GPD by MLE via `Optimize.nelderMead`/L-BFGS and by PWM, threshold selection by mean-excess and stability plots made numeric, HILL with k selection, GEV, return levels with profile-likelihood intervals) and `experimental.stats.SpotThreshold` (SPOT, DSPOT).
- **Experiment:** `experiments.inference.TailsAndDependence` (tail table).
- **Toy task:** `DependenceSamples` heavy-tailed samples with known tail indices and quantiles (n = 500–5000; targets at 1e-3 to 1e-5); streaming anomaly scores from wave 12's `StreamingAnomaly` detectors on `DriftingStreams`, and returns from `MarketPaths`.
- **Baselines:** empirical quantiles; Gaussian-tail extrapolation (`ml.NormalTails`); linear `stats.QuantileRegression` at the target level; the fixed top-k% thresholds used by the anomaly experiments.
- **Expected metric:** relative error of extreme quantiles and interval coverage; realised false-alarm rate vs target for anomaly thresholds. Hypothesis: GPD-POT keeps relative error ≤ 20% at the 1e-4 quantile where the Gaussian tail is off by factors of 2–10 for heavy tails and the empirical quantile is undefined; SPOT's realised false-alarm rate is within 2× of the target where fixed thresholds miss by an order of magnitude, and DSPOT is needed under drift.
- **Source:** Siffer et al., "Anomaly detection in streams with extreme value theory" (KDD 2017); Coles, An Introduction to Statistical Modeling of Extreme Values (2001).

### 13.5.14 Vine copulas: pair-copula constructions with tail-dependent families and Dissmann's tree selection (Joe, 1996; Bedford & Cooke, Annals 2002; Aas et al., IME 2009; Dissmann et al., CSDA 2013)
A d-dimensional copula can be decomposed into d(d−1)/2 bivariate (conditional) pair copulas arranged in a regular vine; choosing Gaussian, Student-t, Clayton (lower-tail), Gumbel (upper-tail) and Frank families per pair captures asymmetric and tail dependence that a single Gaussian copula cannot. Dissmann's algorithm selects the vine trees greedily by maximum spanning trees on |Kendall's τ| and each pair family by AIC; parameters are fitted sequentially by MLE on h-function transforms. Sampling inverts the h-functions.
- **Block:** `experimental.stats.VineCopula` (pair families with h-functions and inverses, C_VINE, D_VINE, R_VINE by Dissmann's MST, sequential MLE via `Optimizer.minimize`, sampling, log density, tail-dependence coefficients; marginals by empirical CDFs or 13.5.13's GPD tails).
- **Experiment:** `TailsAndDependence` (dependence table).
- **Toy task:** `DependenceSamples` 4–8-D vines with known structure and families; `MarketPaths` multi-asset returns with crash co-movement; mixed tabular data from `TabularStressSuite` for synthesis.
- **Baselines:** `SyntheticTraining`'s Gaussian copula with empirical marginals (the existing table source); `DensityFlow`/`GlowFlow` normalising flows; `ConditionalTabularGan` for the tabular-synthesis use.
- **Expected metric:** held-out log-likelihood, error of upper/lower tail-dependence coefficients and of joint exceedance probabilities, structure recovery (share of correct first-tree edges), and train-on-synthetic accuracy for tables. Hypothesis: the R-vine recovers the planted first tree and families and beats the Gaussian copula in held-out likelihood and joint-tail probabilities by large factors; flows match the likelihood on the bulk but underestimate tail dependence at n = 2000; for table synthesis the vine ties the Gaussian copula on accuracy and preserves rare-joint events better.
- **Source:** Aas, Czado, Frigessi & Bakken, "Pair-copula constructions of multiple dependence" (Insurance: Mathematics and Economics 2009); Dissmann et al. (CSDA 2013).

### 13.5.15 Functional data analysis: FPCA for sparse curves (PACE), functional linear regression and functional depth outliers (Ramsay & Silverman, 2005; Yao, Müller & Wang, JASA 2005; Sun & Genton, JCGS 2011)
Functional data are curves observed on grids or at sparse irregular points. Functional PCA estimates the mean and covariance surfaces by smoothing and expands curves in the leading eigenfunctions; PACE handles sparse curves by estimating each curve's scores as conditional expectations (BLUP) under a Gaussian model, rather than by numerical integration. Functional linear regression ∫β(t)X(t)dt is fitted in the FPC basis. Functional boxplots based on band depth and the outliergram flag magnitude and shape outliers.
- **Block:** `experimental.stats.FunctionalData` (smoothing of mean and covariance with wave 12's `PenalizedSplines`, FPCA dense and PACE sparse, FUNCTIONAL_REGRESSION, MODIFIED_BAND_DEPTH, functional boxplot, outliergram).
- **Experiment:** `TailsAndDependence` (functional table).
- **Toy task:** `DependenceSamples` curves from known mean and 3–5 eigenfunctions, observed densely or at 3–10 random points per curve with noise; a scalar outcome from a known β(t); planted shape and magnitude outliers; `IrregularSeries` curves as a realistic sparse case.
- **Baselines:** PCA on curves linearly interpolated to a grid (`ComponentAnalysis`); a `GaussianProcess` fitted per curve; `IrregularSequenceModels` (mTAN-style) for the regression task; `IsolationForest` on interpolated curves for outliers.
- **Expected metric:** eigenfunction recovery (angle), curve reconstruction RMSE at unobserved points, β(t) estimation error and outcome RMSE, outlier detection AUROC. Hypothesis: with 3–5 observations per curve PACE recovers the leading eigenfunctions and reconstructs curves far better than interpolate-then-PCA or per-curve GPs; functional regression beats mTAN at n ≤ 300; band depth catches shape outliers that isolation forests on interpolated values miss.
- **Source:** Yao, Müller & Wang, "Functional data analysis for sparse longitudinal data" (JASA 2005).

### 13.5.16 Amortised model comparison with evidence networks and posterior model probabilities (Radev et al., IEEE TNNLS 2023; Jeffrey & Wandelt, 2023)
Comparing simulators by marginal likelihood needs evidences that are intractable for implicit models. A classifier trained on simulations from all candidate models, with a proper scoring rule, learns posterior model probabilities p(M | x) directly and amortises them over observations; evidence networks train with a loss whose optimum is a monotone transform of the Bayes factor (the "l-POP exponential" loss) and give accurate log Bayes factors even when they are large. Calibration of the predicted model probabilities is checked by simulation.
- **Block:** `experimental.sbi.ModelComparisonNetwork` (CLASSIFIER with cross-entropy, EVIDENCE_NETWORK with the exponential loss for log Bayes factors, calibration diagnostics).
- **Experiment:** `experiments.inference.ModelChecking` (amortised table).
- **Toy task:** `SimulatorSuite` pairs and triples of nested and non-nested simulators (Gaussian vs Student-t noise; SIR vs SEIR; Ricker vs a logistic map), and tractable conjugate pairs where exact Bayes factors are known.
- **Baselines:** evidences from `NestedSampling` and `AnnealedImportanceSampler` on the tractable pairs; rejection-ABC model choice by acceptance rates (`SimulationBasedInference.rejectionAbc`).
- **Expected metric:** error of log Bayes factors against exact values, model-choice accuracy, and calibration error of p(M|x); cost per new observation. Hypothesis: the evidence network's log-Bayes-factor error stays small even at |log BF| ≈ 10–20 where the cross-entropy classifier saturates; both are calibrated in the moderate range; ABC model choice is biased with insufficient summaries; amortised methods are ~10⁴× cheaper per new observation than nested sampling.
- **Source:** Radev et al., "Amortized Bayesian model comparison with evidential deep learning" (IEEE TNNLS 2023); Jeffrey & Wandelt, "Evidence networks: simple losses for fast, amortized, neural Bayesian model comparison" (2023).

### 13.6.1 Dictionary-based series classification: SAX/SFA words, BOSS and WEASEL 2.0 (Schäfer, DMKD 2015; Schäfer & Leser, CIKM 2017; Schäfer & Leser, MLJ 2023)
Dictionary methods slide a window over the series, turn each window into a short symbolic word and classify by word-count histograms, which captures how often local patterns occur regardless of where. BOSS uses Symbolic Fourier Approximation (truncated DFT coefficients quantised by multiple-coefficient binning) with a 1-NN on histogram distances and an ensemble over window sizes; WEASEL adds bigrams, many window lengths and χ²-based feature selection with a logistic regression; WEASEL 2.0 uses dilation and randomised parameters with a ridge classifier, in the style of ROCKET.
- **Block:** `experimental.tsc.SymbolicFourier` (SFA with MCB and information-gain binning; SAX), `experimental.tsc.Boss` and `experimental.tsc.Weasel` (v1 and 2.0).
- **Experiment:** `experiments.timeseries.SeriesClassifiers`.
- **Toy task:** `SeriesArchive` dictionary-type, shapelet and phase-shifted tasks and `SeriesClassificationTasks`.
- **Baselines:** `RandomConvolutionFeatures` (ROCKET and MiniRocket) with `RidgeClassifier`; 1-NN `DynamicTimeWarping`; `ScatteringTransform`; the MLP/TCN baselines of `SeriesClassification`.
- **Expected metric:** accuracy and fit+predict time. Hypothesis: BOSS and WEASEL win on dictionary-type tasks (pattern frequency) where DTW-1NN fails, and lose on interval tasks; WEASEL 2.0 matches MiniRocket's average accuracy at similar time.
- **Source:** [arXiv:1701.07681](https://arxiv.org/abs/1701.07681) (WEASEL); Schäfer, "The BOSS is concerned with time series classification in the presence of noise" (DMKD 2015).

### 13.6.2 Hydra: competing convolutional kernels (Dempster, Schmidt & Webb, DMKD 2023)
Hydra organises random convolutional kernels into groups; for each time step, the kernels in a group compete, and the counts of how often each kernel wins (and its max response) form the features, so the representation sits between ROCKET's pooled kernel features and dictionary methods' pattern counts. It uses dilation like ROCKET and a ridge classifier; MultiRocket-Hydra concatenates both feature sets.
- **Block:** `experimental.tsc.Hydra` (groups g, kernels per group k, dilations, soft and hard counting, first-difference input) and a MULTIROCKET_HYDRA concatenation option.
- **Experiment:** `SeriesClassifiers` (convolution table).
- **Toy task:** all `SeriesArchive` and `SeriesClassificationTasks` tasks.
- **Baselines:** ROCKET and MiniRocket (`RandomConvolutionFeatures`); 13.6.1's WEASEL 2.0.
- **Expected metric:** accuracy, rank over tasks, and time. Hypothesis: Hydra beats ROCKET on dictionary-type tasks and ties elsewhere at lower cost; MultiRocket-Hydra has the best mean rank of the convolution methods.
- **Source:** [arXiv:2203.13652](https://arxiv.org/abs/2203.13652)

### 13.6.3 Interval methods: QUANT and the time series forest / DrCIF family (Dempster, Schmidt & Webb, DMKD 2024; Deng et al., Inf. Sci. 2013; Middlehurst, Large & Bagnall, 2020)
Interval methods summarise fixed intervals of the series. QUANT is minimalist: it takes dyadic intervals of the series and of its first and second differences and Fourier transform, computes quantiles of each interval as features, and trains an extremely randomised trees classifier; it is fast and among the most accurate interval methods. The time series forest draws random intervals and uses mean, standard deviation and slope per tree; DrCIF adds catch22 features and several representations.
- **Block:** `experimental.tsc.Quant` (dyadic intervals, quantile features, representations) and `experimental.tsc.IntervalForest` (TSF and a DrCIF-lite with a small fixed feature set), with an `ExtraTrees` mode added inside the block (random thresholds, no bootstrap) on top of `experimental.ml.RandomForest`'s tree code if its API allows, else a local extremely randomised tree.
- **Experiment:** `SeriesClassifiers` (interval table).
- **Toy task:** `SeriesArchive` interval-type tasks and the full task set.
- **Baselines:** ROCKET/MiniRocket; `RandomForest` on raw values; 13.6.2's Hydra.
- **Expected metric:** accuracy, rank and time. Hypothesis: QUANT wins on interval-type tasks and is competitive overall at the lowest time; TSF trails QUANT; random forests on raw values fail on phase-shifted interval tasks.
- **Source:** [arXiv:2308.00928](https://arxiv.org/abs/2308.00928) (QUANT); Deng et al., "A time series forest for classification and feature extraction" (Inf. Sci. 2013).

### 13.6.4 Combining classifiers and the meta-learning gap: Hydra + QUANT stacking and CAWPE (Large, Lines & Bagnall, DMKD 2019; Maniar, Dec 2025)
State-of-the-art series classifiers (HIVE-COTE) ensemble different representations. CAWPE weights each member's class probabilities by its cross-validated accuracy raised to a power. The Dec 2025 study of Hydra and QUANT tries feature concatenation, asymmetric stacking (QUANT features with Hydra's out-of-fold logits), symmetric stacking and CAWPE: the best gains ~0.7 points over the best single method, but prediction-combination ensembles capture only ~11% of the oracle (best per-example member) potential — a "meta-learning gap".
- **Block:** `experimental.tsc.SeriesEnsembles` (CONCAT, ASYMMETRIC_STACK, SYMMETRIC_STACK with out-of-fold logits and an extra-trees or ridge meta-learner, CAWPE with exponent α; oracle accuracy).
- **Experiment:** `SeriesClassifiers` (ensemble table).
- **Toy task:** all `SeriesArchive` tasks with 13.6.1–13.6.3's members.
- **Baselines:** the best single member per task; `EnsembleShootout`'s stacking pattern (read-only, for tabular stacking); majority voting.
- **Expected metric:** accuracy, gain over the best member, and the share of the oracle gap closed. Hypothesis: stacking and CAWPE gain 0.5–2 points on average and close well under half of the oracle gap, reproducing the meta-learning gap; feature concatenation with extra trees is the best single strategy, as in the 2025 study.
- **Source:** [arXiv:2512.06666](https://arxiv.org/abs/2512.06666); Large, Lines & Bagnall, "A probabilistic classifier ensemble weighting scheme based on cross-validated accuracy estimates" (DMKD 2019).

### 13.6.5 Deep series classifiers: FCN, ResNet, InceptionTime and LITE (Wang, Yan & Oates, IJCNN 2017; Ismail Fawaz et al., DMKD 2020; Ismail-Fawaz et al., DSAA 2023)
Fully convolutional networks with global average pooling and a 1-D ResNet are the standard deep baselines. InceptionTime stacks inception modules (bottleneck, parallel convolutions with kernel lengths 10/20/40, max-pool branch) with residual connections and ensembles five networks. LITE cuts parameters ~9× with depthwise-separable convolutions, dilation, multiplexing and hand-crafted fixed filters (increase, decrease, peak detectors), keeping accuracy close.
- **Block:** `experimental.tsc.DeepSeriesClassifiers` (FCN, RESNET1D, INCEPTION_TIME with ensemble size, LITE).
- **Experiment:** `SeriesClassifiers` (deep table).
- **Toy task:** `SeriesArchive` tasks with 100–500 training series of length ≤ 128.
- **Baselines:** the TCN, MLP and TimesNet classifiers already in `SeriesClassification`; ROCKET; 13.6.2's Hydra.
- **Expected metric:** accuracy, parameters, training time. Hypothesis: InceptionTime beats FCN/ResNet and the TCN on warped and multi-scale tasks; LITE is within 1–2 points of InceptionTime with ~10× fewer parameters; ROCKET-family methods remain more accurate per second of compute at these sizes.
- **Source:** [arXiv:1909.04939](https://arxiv.org/abs/1909.04939) (InceptionTime)

### 13.6.6 Elastic distances, the Elastic Ensemble and Proximity Forest (Chen & Ng, VLDB 2004; Stefan, Athitsos & Das, TKDE 2013; Marteau, TPAMI 2009; Lines & Bagnall, DMKD 2015; Lucas et al., DMKD 2019)
DTW is one of many elastic distances: ERP (edit distance with real penalty, a metric), MSM (move–split–merge, a metric), TWE (time warp edit with stiffness), LCSS, weighted and derivative DTW. The Elastic Ensemble combines 1-NN classifiers with eleven such distances, weighted by cross-validated accuracy. Proximity Forest builds trees whose splits pick a random distance and parameters and branch by the nearest of random exemplars per class, giving EE's accuracy at a fraction of the cost.
- **Block:** `experimental.tsc.ElasticDistances` (DTW with window, WDTW, DDTW, LCSS, ERP, MSM, TWE; lower bounds LB_Keogh) and `experimental.tsc.ProximityForest` (and an ELASTIC_ENSEMBLE of 1-NN classifiers).
- **Experiment:** `SeriesClassifiers` (elastic table).
- **Toy task:** `SeriesArchive` warped-template, phase-shifted and two-patterns tasks.
- **Baselines:** 1-NN `DynamicTimeWarping` (existing, full window and the block's windowed variant); ROCKET.
- **Expected metric:** accuracy and time. Hypothesis: MSM or TWE beats DTW on several warped tasks; the Elastic Ensemble beats any single distance; Proximity Forest matches EE at ≥ 10× less time; ROCKET is still faster at similar accuracy.
- **Source:** [arXiv:1808.10594](https://arxiv.org/abs/1808.10594) (Proximity Forest); Lines & Bagnall, "Time series classification with ensembles of elastic distance measures" (DMKD 2015).

### 13.6.7 Soft-DTW losses, DTW barycentre averaging and k-Shape clustering (Cuturi & Blondel, ICML 2017; Petitjean, Ketterlin & Gançarski, PR 2011; Paparrizos & Gravano, SIGMOD 2015)
Soft-DTW replaces the minimum in DTW's recursion by a soft-min with temperature γ, giving a differentiable loss whose gradient is computed by a backward recursion; it can train forecasters that tolerate time shifts and average series. DBA computes a DTW barycentre by iteratively aligning series to the current average and averaging aligned points. k-Shape clusters by shape-based distance (normalised cross-correlation via FFT) with centroids from the leading eigenvector of a shape-aligned matrix.
- **Block:** `experimental.tsc.SoftDtw` (value and gradient, as a `Var` loss, and soft-DTW barycentres), `experimental.tsc.DtwBarycenter` (DBA) and `experimental.tsc.KShape`.
- **Experiment:** `experiments.timeseries.ElasticClustering`.
- **Toy task:** `SeriesArchive` warped templates for clustering and averaging; `SeasonalSeries`/`ChaoticSeries` multi-step forecasting with a soft-DTW loss (phase-tolerant targets).
- **Baselines:** `KMeans` on raw series; DTW k-medoids (with `DynamicTimeWarping`); `SpectralClustering` on DTW affinities; MSE-trained forecasters (the same network) for the loss comparison.
- **Expected metric:** ARI for clustering, DTW distance of barycentres to the true template, and forecast MSE/DTW error. Hypothesis: k-Shape and DBA-based k-means beat Euclidean k-means on shifted and warped templates by large ARI margins; soft-DTW barycentres are closer to the template than the Euclidean mean; soft-DTW-trained forecasters have lower DTW error but higher MSE than MSE-trained ones, keeping sharp peaks.
- **Source:** [arXiv:1703.01541](https://arxiv.org/abs/1703.01541) (soft-DTW); Paparrizos & Gravano, "k-Shape" (SIGMOD 2015).

### 13.6.8 Tabular self-supervised pretraining: VIME, SCARF, SubTab and mask-and-recover, under label scarcity (Yoon et al., NeurIPS 2020; Bahri et al., ICLR 2022; Ucar, Hajiramezanali & Edwards, NeurIPS 2021; Mazrouei, 2026)
Tabular SSL corrupts features by resampling them from their marginals: VIME pretrains an encoder to predict the corruption mask and reconstruct the values (and uses consistency regularisation for semi-supervised fine-tuning); SCARF trains with a contrastive InfoNCE loss between a row and its randomly corrupted view; SubTab splits features into subsets and reconstructs the full row from each. A 2026 study with identical encoders finds that these objectives do not differ significantly, that random forests remain strong at 10% labels, and that SSL helps most under test-time missingness, though not significantly after correction.
- **Block:** `experimental.tabular.TabularPretraining` (VIME mask + value heads, SCARF with `SelfSupervisedLosses.ntXent`, SUBTAB, MASK_RECOVER; shared MLP encoder; linear-probe and fine-tune heads).
- **Experiment:** `experiments.selfsupervised.TabularPretraining`.
- **Toy task:** `TabularStressSuite` tasks with 1%, 5%, 10% and 100% of labels and test-time MCAR/MNAR missingness.
- **Baselines:** the same MLP from scratch; `RandomForest` and core `GradientBoostedTrees`; TabM/RealMLP-style models from `experiments.recsys.TabularShootout` (read-only).
- **Expected metric:** AUROC/accuracy against label share and under missingness, mean over 3 seeds with seed spread. Hypothesis: pretraining helps the MLP at 1–5% labels by a few points, with no significant differences among VIME, SCARF and SubTab; tree ensembles remain best at ≥ 10% labels; SSL encoders are more robust to test-time missingness than scratch MLPs; single-seed comparisons are misleading, as the 2026 study warns.
- **Source:** [arXiv:2106.15147](https://arxiv.org/abs/2106.15147) (SCARF); [arXiv:2608.24381](https://arxiv.org/abs/2608.24381) (2026 study); Yoon et al., "VIME" (NeurIPS 2020).

### 13.6.9 Mutual-information-guided structured corruption for tabular SSL (Lawson et al., ICML 2026)
SCARF corrupts random features independently, which ignores dependence: corrupting one of two highly dependent features is easy to undo. The ICML 2026 method estimates pairwise mutual information, groups features by dependence, and corrupts whole groups jointly, generating realistic replacements for a group from a conditional VAE given the remaining features, so the pretext task cannot be solved by copying from correlated columns.
- **Block:** `experimental.tabular.StructuredCorruption` (pairwise MI by wave 12's `estimators.MutualInformation` KSG, grouping by agglomerative clustering (`ml.AgglomerativeClustering`), GROUP_MARGINAL and GROUP_CVAE replacement) plugged into 13.6.8's SCARF objective.
- **Experiment:** `TabularPretraining` (structured table).
- **Toy task:** `TabularStressSuite` tasks plus a variant with planted feature blocks of high redundancy (duplicated noisy copies).
- **Baselines:** 13.6.8's SCARF with random corruption; VIME; scratch MLP; GBT.
- **Expected metric:** linear-probe and fine-tune accuracy at 1–10% labels, and the pretext loss gap between random and group corruption. Hypothesis: group corruption beats random corruption on the redundant-block tasks by several points of linear-probe accuracy and ties elsewhere; marginal group replacement gets most of the gain, the CVAE adds a little.
- **Source:** [ICML 2026 poster](https://icml.cc/virtual/2026/71753)

### 13.6.10 Distributionally robust optimisation beyond groups: CVaR, χ² and KL uncertainty sets, and Wasserstein DRO (Duchi & Namkoong, Annals 2021; Levy, Carmon, Duchi & Sidford, NeurIPS 2020; Shafieezadeh-Abadeh, Mohajerin Esfahani & Kuhn, NeurIPS 2015)
GroupDRO needs group labels. f-divergence DRO minimises the worst-case loss over reweightings of the training distribution within a divergence ball: CVaR-DRO averages the worst α-fraction of losses, χ²-DRO and KL-DRO (a soft-max over losses with a temperature) have closed-form dual weights computed per minibatch, with the large-scale minibatch estimators of Levy et al. Wasserstein DRO protects against covariate perturbations; for logistic regression it reduces to a convex program equivalent to a norm-regularised loss with a dual-norm penalty.
- **Block:** `experimental.robust.DistributionalRobustness` (CVAR, CHI_SQUARE, KL with minibatch dual weights, WASSERSTEIN_LOGISTIC as a convex program via L-BFGS on its regularised form).
- **Experiment:** `experiments.robustness.DistributionallyRobust`.
- **Toy task:** `ShiftSuites` subpopulation-shift tasks with hidden minority groups (group labels withheld at training), `ToyTasks` digits with class imbalance, and adversarially perturbed tabular test sets from `TabularStressSuite` for the Wasserstein case.
- **Baselines:** ERM; `GroupRobustTraining` (GroupDRO with group labels, as the oracle, and JTT without them); `AdversarialTraining` (PGD) for the covariate-perturbation case; L2 logistic regression.
- **Expected metric:** worst-group accuracy, average accuracy, and accuracy under ε-perturbations. Hypothesis: CVaR and χ²-DRO raise worst-group accuracy over ERM without group labels but stay below GroupDRO and roughly match JTT, at some average-accuracy cost; they are sensitive to label noise (upweighting mislabelled points); Wasserstein-DRO logistic regression matches PGD training's robust accuracy at a fraction of the cost for linear models.
- **Source:** [arXiv:2010.05893](https://arxiv.org/abs/2010.05893) (Levy et al.), [arXiv:1810.08750](https://arxiv.org/abs/1810.08750) (Duchi & Namkoong)

### 13.6.11 Conformal survival analysis: lower predictive bounds under type-I and general right censoring, and the doubly robust version (Candès, Lei & Ren, JRSS-B 2023; Davidov et al., ICLR 2025; Sesia & Svetnik, ICML 2025)
A survival model's predicted quantile is not a guaranteed lower bound on a patient's survival time. Conformalised survival analysis gives a lower predictive bound (LPB) with P(T ≥ L(X)) ≥ 1 − α: with type-I censoring (censoring times observed for everyone) it calibrates on units whose censoring time exceeds a threshold, reweighted by the censoring-time propensity as a covariate-shift problem. Davidov et al. extend this to general right censoring, where only min(T, C) is observed. Sesia and Svetnik impute the unobserved censoring times with a model, then calibrate with weighted conformal inference, and show double robustness: validity holds asymptotically if either the censoring model or the survival model is accurate.
- **Block:** `experimental.survival.ConformalSurvival` (TYPE_I_LPB, GENERAL_CENSORING_LPB, DOUBLY_ROBUST with censoring imputation by `SurvivalForest` or a Cox model; any base survival model).
- **Experiment:** `experiments.survival.ConformalSurvival` (conformal table).
- **Toy task:** `SurvivalData` with known event and censoring times, censoring 20–60%, censoring that depends on covariates, and a misspecified base model.
- **Baselines:** uncalibrated quantiles of `SurvivalModels` (Cox), `AftModels` and `SurvivalForest`; naive split conformal treating censored times as events; `ConformalSets`-style conformal quantile regression ignoring censoring.
- **Expected metric:** empirical coverage P(T ≥ L(X)) (computable from the simulated true times) and mean bound tightness E[L(X)]/E[T]. Hypothesis: uncalibrated model quantiles under- or over-cover by 10–30 points under misspecification; naive conformal is conservative and loose; all three conformal methods hit nominal coverage, with the doubly robust method keeping coverage when the survival model is wrong but the censoring model is right, and the tightest bounds when both are reasonable.
- **Source:** [arXiv:2103.09763](https://arxiv.org/abs/2103.09763); [ICLR 2025](https://mlanthology.org/iclr/2025/davidov2025iclr-conformalized); [ICML 2025](https://proceedings.mlr.press/v267/sesia25a.html)

### 13.6.12 Cure models and Fine–Gray subdistribution hazards with the Aalen–Johansen estimator (Farewell, Biometrics 1982; Kuk & Chen, Biometrika 1992; Fine & Gray, JASA 1999; Aalen & Johansen, Scand. J. Stat. 1978)
When a fraction of subjects never experience the event (cured), standard models misestimate both incidence and latency; the mixture cure model combines a logistic model for being susceptible with a Cox or Weibull model for the latency of susceptibles, fitted by EM. With competing risks, the Aalen–Johansen estimator gives cumulative incidence functions nonparametrically, and the Fine–Gray model regresses covariates directly on the subdistribution hazard of one cause (keeping subjects who failed from other causes in the risk set with weights), so coefficients describe effects on cumulative incidence rather than on cause-specific hazards.
- **Block:** `experimental.survival.CureModel` (MIXTURE_CURE with logistic incidence and Weibull or semiparametric Cox latency, EM) and `experimental.survival.CompetingRisks` (AALEN_JOHANSEN, FINE_GRAY with IPCW weights by Newton or L-BFGS).
- **Experiment:** `experiments.survival.ConformalSurvival` (models table).
- **Toy task:** `SurvivalData` with a planted cured fraction (20–50%) and long follow-up; two competing causes with covariate effects that differ between cause-specific and subdistribution hazards.
- **Baselines:** `SurvivalModels` Cox and Kaplan–Meier ignoring the cure fraction; cause-specific Cox and `DeepHit`'s cumulative incidence (wave 9, the existing competing-risks rows); 1 − Kaplan–Meier treating other causes as censoring (the known biased estimator).
- **Expected metric:** error of the estimated cure fraction and incidence coefficients; cumulative-incidence error per cause; C-index and integrated Brier score. Hypothesis: the cure model recovers the cured fraction within a few points where Cox mis-estimates long-term survival; 1 − KM overestimates cumulative incidence by the competing cause's share, Aalen–Johansen is unbiased; Fine–Gray's coefficients match the planted subdistribution effects where cause-specific Cox's do not, while DeepHit's CIFs are competitive but less sample-efficient at n = 500.
- **Source:** Fine & Gray, "A proportional hazards model for the subdistribution of a competing risk" (JASA 1999); Kuk & Chen, "A mixture model combining logistic regression with proportional hazards regression" (Biometrika 1992).

### 13.6.13 Randomised-weight networks: extreme learning machines, RVFL and deep/ensemble RVFL (Huang, Zhu & Siew, Neurocomputing 2006; Pao, Park & Sobajic, Neurocomputing 1994; Katuwal & Suganthan, 2019)
An extreme learning machine fixes random hidden weights and solves only the output layer by ridge regression in closed form. The random vector functional link network adds direct input–output links, which consistently improves accuracy; deep RVFL stacks random layers with direct links from every layer to the output, and ensemble deep RVFL trains one output per layer and votes. They are the shallow, training-free relatives of random-feature methods.
- **Block:** `experimental.ml.RandomWeightNetworks` (ELM, RVFL with direct links, DEEP_RVFL, ENSEMBLE_DEEP_RVFL; activation and scaling choices; ridge via core `LeastSquares`).
- **Experiment:** `experiments.classic.KernelLearners` (random-weight table).
- **Toy task:** `TabularStressSuite` classification and regression tasks; `ToyTasks` digits and spirals.
- **Baselines:** `RandomFourierFeatures` with ridge; `KernelSvm` (RBF); an MLP trained by Adam; `NystromKernelRidge`; a plain linear ridge read-out on the raw features (the real-valued linear baseline wave 12 WP2 could not get from `FtrlProximal`, which stays unchanged).
- **Expected metric:** accuracy/RMSE and training time. Hypothesis: RVFL's direct links give +1–5 points over ELM; ensemble deep RVFL approaches the MLP and kernel SVM at a fraction of the training time; RFF and ELM are equivalent at equal width on smooth tasks.
- **Source:** Huang, Zhu & Siew, "Extreme learning machine: theory and applications" (Neurocomputing 2006); Katuwal & Suganthan, "Stacked autoencoder based deep random vector functional link neural network for classification" (2019).

### 13.6.14 Multiple kernel learning: SimpleMKL, EasyMKL and centred-alignment MKL (Rakotomamonjy et al., JMLR 2008; Aiolli & Donini, Neurocomputing 2015; Cortes, Mohri & Rostamizadeh, JMLR 2012)
Instead of tuning one kernel, MKL learns a non-negative combination Σ_m μ_m K_m of base kernels (different bandwidths, or kernels on different feature groups). SimpleMKL alternates an SVM solve with a reduced-gradient step on the simplex of weights; EasyMKL maximises the margin between class centroids in the combined space in closed form, scaling to many kernels; alignment-based MKL picks weights maximising the centred alignment of the combined kernel with the label kernel, a two-stage method with generalisation guarantees.
- **Block:** `experimental.ml.MultipleKernelLearning` (SIMPLE_MKL with `KernelSvm` as the inner solver, EASY_MKL, ALIGNF centred alignment by a small QP via `Optimize`), base kernels from `KernelFunction`.
- **Experiment:** `KernelLearners` (MKL table).
- **Toy task:** `TabularStressSuite` tasks with heterogeneous feature groups (one kernel per group) and multi-scale synthetic tasks (one kernel per bandwidth).
- **Baselines:** `KernelSvm` with a single RBF kernel tuned by cross-validation; the uniform kernel average; `GaussianProcess` with ARD lengthscales (marginal-likelihood kernel learning); `SpectralMixtureKernel`.
- **Expected metric:** accuracy, learned weights (do they select the informative groups?), and training time. Hypothesis: MKL matches or beats the CV-tuned single kernel and selects the informative groups; the uniform average is surprisingly competitive (as often reported); EasyMKL is ≥ 10× faster than SimpleMKL at equal accuracy; ARD-GP matches MKL on group selection at higher cost.
- **Source:** Rakotomamonjy et al., "SimpleMKL" (JMLR 2008); Cortes, Mohri & Rostamizadeh, "Algorithms for learning kernels based on centered alignment" (JMLR 2012).

### 13.6.15 Adaptive resonance theory: Fuzzy ART and Fuzzy ARTMAP for stable incremental learning (Carpenter, Grossberg & Rosen, Neural Networks 1991; Carpenter et al., IEEE TNN 1992)
ART networks learn categories online without catastrophic forgetting: an input (complement-coded) activates the category with the highest choice function; if its match exceeds the vigilance ρ the category's weights move towards the input (fuzzy AND), otherwise the category is reset and the search continues, creating a new category if none resonates. Fuzzy ARTMAP couples two ART modules with a map field and match tracking, raising vigilance just enough after a wrong prediction, so supervised learning is one-pass and incremental.
- **Block:** `experimental.ml.AdaptiveResonance` (FUZZY_ART, FUZZY_ARTMAP with match tracking, vigilance, fast and slow learning).
- **Experiment:** `experiments.classic.PrototypeLearners` (ART table).
- **Toy task:** `ToyTasks` digits and spirals presented class-incrementally (tasks in sequence) and in a drifting stream from `DriftingStreams`; one-pass learning.
- **Baselines:** `SelfOrganizingMap` and `GrowingNeuralGas` (unsupervised prototype learners, with a labelled read-out); k-NN (`KnnIndex`); an MLP fine-tuned sequentially (forgetting) and with replay (the continual-learning reference).
- **Expected metric:** final accuracy on all classes after class-incremental training, forgetting, number of categories, and one-pass accuracy. Hypothesis: Fuzzy ARTMAP shows near-zero forgetting where the sequential MLP forgets earlier classes, with accuracy close to k-NN and far fewer stored prototypes at a suitable vigilance; it is sensitive to vigilance and input order (category proliferation on noisy data).
- **Source:** Carpenter et al., "Fuzzy ARTMAP: a neural network architecture for incremental supervised learning of analog multidimensional maps" (IEEE TNN 1992).

### 13.6.16 Soft-sharing multi-task architectures: cross-stitch units, sluice networks and MTAN-style task attention (Misra et al., CVPR 2016; Ruder et al., AAAI 2019; Liu, Johns & Davison, CVPR 2019)
Hard parameter sharing forces all tasks through one trunk. Cross-stitch units give each task its own network and learn linear combinations of their activations at each layer; sluice networks also learn which layers and subspaces to share and add skip connections to the output; MTAN keeps a shared trunk and gives each task soft attention masks over its features. The architecture question is separate from loss weighting (PCGrad, CAGrad, FAMO, already in `experimental.multitask`).
- **Block:** `experimental.multitask.SoftSharing` (CROSS_STITCH, SLUICE with subspace split and layer skips, TASK_ATTENTION (MTAN-style)), usable with any `LossWeighting`/`GradientSurgery` scheme.
- **Experiment:** `experiments.multitask.SharingArchitectures`.
- **Toy task:** the multi-task tasks of `experiments.multitask.GradientBalancing` (read-only) and `ShapeImages` with related and conflicting tasks (shape, colour, position regression).
- **Baselines:** hard sharing; separate single-task networks; `MultiGateExperts` (MMoE); hard sharing with `ParetoDescent`/`GradientSurgery` (the loss-side fix).
- **Expected metric:** per-task metrics and the average relative improvement Δ_MTL over single-task networks, at matched parameters. Hypothesis: soft sharing beats hard sharing on conflicting tasks by a few points of Δ_MTL and ties on related ones; learned cross-stitch weights move towards task separation in late layers; MMoE and MTAN are close, and gradient-surgery methods give a comparable gain that is partly additive with soft sharing.
- **Source:** [arXiv:1604.03539](https://arxiv.org/abs/1604.03539) (cross-stitch), [arXiv:1705.08142](https://arxiv.org/abs/1705.08142) (sluice), [arXiv:1803.10704](https://arxiv.org/abs/1803.10704) (MTAN)

### 13.6.17 Learning vector quantisation with learned metrics: GLVQ, GMLVQ and localised relevance (Kohonen, 1990; Sato & Yamada, NeurIPS 1995; Schneider, Biehl & Hammer, Neural Comput. 2009)
LVQ classifies by the nearest labelled prototype and moves prototypes towards same-class and away from other-class samples. Generalised LVQ minimises a smooth cost of the relative distance difference μ = (d⁺ − d⁻)/(d⁺ + d⁻), giving stable gradient training; GMLVQ also learns a full relevance matrix Λ = ΩᵀΩ in the distance (x − w)ᵀΛ(x − w), which yields an interpretable feature-relevance profile and often large accuracy gains; localised variants learn one matrix per prototype or class.
- **Block:** `experimental.ml.VectorQuantization` (LVQ1, LVQ2.1, GLVQ, GMLVQ, LOCALISED_GMLVQ; prototypes per class; relevance matrices with trace normalisation).
- **Experiment:** `PrototypeLearners` (LVQ table).
- **Toy task:** `TabularStressSuite` classification tasks with irrelevant and scaled features, `ToyTasks` digits, and a task with correlated relevant features where a diagonal metric is insufficient.
- **Baselines:** k-NN with Euclidean distance (`KnnIndex`); nearest class mean; `SelfOrganizingMap` with a labelled read-out; logistic regression and an MLP; the metric-learning losses (`PairLosses` triplet on a linear map) as the deep-metric reference.
- **Expected metric:** accuracy, number of prototypes, and correlation of the learned relevance profile with the planted relevant features. Hypothesis: GMLVQ with one prototype per class matches k-NN on the full training set and beats Euclidean GLVQ by 5–15 points when irrelevant or rescaled features are present; its relevance matrix recovers the planted features; localised GMLVQ wins on the correlated-feature task.
- **Source:** Schneider, Biehl & Hammer, "Adaptive relevance matrices in learning vector quantization" (Neural Computation 2009).
